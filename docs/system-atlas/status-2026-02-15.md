## Current goal (north star)

Deliver a V10 pipeline that is:
- **SSOT‑strict** (Facts → Contract Context → Procedure Graph → Chips → Output/Billing)
- **KZV‑safe** (documentation evidence is sourced and never fabricated)
- **Low‑friction** (defaults from Settings, minimal askbacks, no hard errors)
- **Deterministic** (same input → same output)
- **Scalable** (new treatments are configured, not patched)

## Pending work (prioritized plan)

### P0 — Strict KZV mode (evidence askbacks)
1) **Add a “Strict KZV” flag** in Settings (practice‑level) and wire to Procedure Graph.
2) **Askback gating**:
   - If strict mode on: ask for missing evidence in Cp/P cases (QBÜ‑RL‑Z list).
   - If strict mode off: evidence askbacks should be **optional/hidden**.
3) **Radiology evidence**:
   - If radiology is billed, require indication/type/timing/findings; otherwise optional.

### P0 — Output length policy enforcement
1) **Make “kurz/mittel/lang” deterministic** for all active chips + disclosures.
2) **Ensure disclosures have variants** (no single‑text disclosures in “kurz”).
3) **Template policy**: ensure section ordering matches the Output Contract:
   - Befund → Aufklärung → Behandlungsablauf → Leistungen → Hinweise → Abrechnung

### P1 — One treatment end‑to‑end migration (Füllung or Endo)
1) **Procedure nodes for core events** (Cp/P, anesthesia, isolation, finishing).
2) **Materials from Settings** (when missing in dictation).
3) **Constraints** (Cp vs P, MKV channeling) enforced in nodes, not ad‑hoc.
4) **Remove legacy emitters** for the chosen treatment (chipActivation, askback.chipEffect, defaultActive).

### P1 — Gates to prevent regressions
1) **Unknown chip emitter gate** must be WARN→BLOCK once migration starts.
2) **Missing event bundles** gate must cover all chips for the migrated treatment.
3) **Settings↔Askback mapping** coverage must be > 0 and enforced.

### P2 — UI cohesion (3‑step flow)
1) **Step 2 UI** (Questions / extracted facts) should visually match Step 1:
   - large typography, soft layers, minimal borders, jeton.com‑style spacing.
2) **Show defaults & extracted facts** in the same visual language as askbacks.
3) **No redundant buttons**; only essential controls + intentional design elements.
