## Why it happened (root cause)
- **Trace format mismatch**: ExplainRun assumed `{ key, value }` objects, while pipeline emits V7-style `"stage:detail"` strings in `meta.traceLines`.
- **Over-eager normalization**: MKV flags were reset too early for *all* non-MKV insurance types, including GKV, overriding extraction signals.
- **Placeholder policy**: Template placeholders were only replaced if a value existed; empty values left placeholders intact.
