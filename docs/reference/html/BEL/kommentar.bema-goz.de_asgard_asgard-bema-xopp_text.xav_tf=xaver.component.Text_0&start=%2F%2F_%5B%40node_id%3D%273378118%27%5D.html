Erläuterungen zum Leistungsinhalt

Erläuterungen zur Abrechnung
Die L-Nr. 808 0 ist je Prothese oder KFO-/FKO-Basis einmal abrechenbar.
Die L-Nr. 808 0 ist keine Instandsetzung im Sinne der L-Nrn. 801 0, 802 1 – 802 7, 861 0, 862 0 und 863 0.
Für die Fixierung der Bisslage mit einem zweiten Modell und dem Einstellen in einen Fixator sind die L-Nrn. 001 0 und 011 2, nicht jedoch die L-Nr. 012 0 abrechenbar.
▶ Kommentar zur BEL-L-Nr. 808 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Soll nur ein Teil einer ansonsten umfangreicheren Basis einer partiellen oder totalen Prothese oder eines kieferorthopädischen Gerätes unterfüttert werden, so ist hierfür die L-Nr. 808 0 anzusetzen.
Für die Unterfütterung ist diese L-Nr. also die alleinige Leistung.
Fallen im Rahmen der Teilunterfütterung weitere Leistungen der Instandsetzung/Wiederherstellung/Erweiterung an, so sind diese Leistungen nach den in den Erläuterungen zur Abrechnung genannten L-Nrn. aufzuführen.
Bei Unterfütterungen von Prothesen mit konfektionierten oder individuellen Verbindungselementen ist die Sicherung dieser Elemente (z. B. durch Auswachsen/Ausfetten) im Leistungsinhalt der L-Nr. 808 0 enthalten. Unter dem Begriff „Sicherung von vorhandenen Verbindungselementen“ ist jedoch nicht die fallbezogene Verwendung von Kunststoff oder das Einfügen eines Platzhalters zu verstehen.
Bei Unterfütterungen von kieferorthopädischen Geräten kann es zum durch die Unterfütterung bedingten Verschluss des Trennspaltes kommen; für das erneute Trennen der Basis ist die L-Nr.
722 0 
Trennen einer Basis
anzusetzen.
Leistungsanwendung
Eigenständige Leistung bei Teil-Unterfütterung einer partiellen oder totalen Prothese oder eines kieferorthopädischen Gerätes, auch bei gleichzeitiger Instandsetzungs-, Wiederherstellungs- und/oder Erweiterungsmaßnahme abrechenbar.
