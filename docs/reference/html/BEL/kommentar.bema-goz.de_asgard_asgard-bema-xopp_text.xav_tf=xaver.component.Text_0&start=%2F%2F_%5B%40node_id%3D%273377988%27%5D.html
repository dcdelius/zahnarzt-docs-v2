Basis aus Kunststoff (ohne Bisswall)

Kurztext laut Anlage 2
021 3Basis für Bissregistrierung
Erläuterungen zum Leistungsinhalt
Basis aus Kunststoff für Bissregistrierung bei einem teilbezahnten oder zahnlosen Kiefer für das Aufbringen eines Bisswalls aus Wachs oder Kunststoff.
Erläuterungen zur Abrechnung
Für das Aufbringen eines Bisswalls aus Wachs oder Kunststoff auf eine Basis nach L-Nr. 021 3 ist die L-Nr. 022 0 je Basis einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 021 3
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die Basis für Bissregistrierung wird in der Regel aus selbsthärtendem Kunststoff hergestellt. Sie wird ergänzt durch einen Bisswall (L-Nr. 022 0) und wird so zu einem Hilfsmittel für die einfache Bissregistrierung.
Leistungsanwendung
Wenn mehr als einmal je Kiefer eine Bissregistrierung vorgenommen werden muss, ist die Leistung Nr. 021 3 sowie die sie ergänzende Leistung Nr. 022 0 entsprechend ihrer erbrachten Menge abrechenbar.
Die Abrechnung der Leistungsnummern 021 3 und 022 0 erstreckt sich auf alle Bereiche zahntechnischer Leistungen.
