Umarbeiten einer vorhandenen Prothese oder eines Aufbissbehelfs zum Aufbissbehelf mit adjustierter Oberfläche
Kurztext laut Anlage 2
403 0Umarbeiten zum Aufbissbehelf
Erläuterungen zum Leistungsinhalt
– 
Prothese umarbeiten zum adjustierten Aufbissbehelf
– 
Adjustieren eines vorhandenen nichtadjustierten Aufbissbehelfs
– 
Neu adjustieren eines vorhandenen adjustierten Aufbissbehelfs
jeweils unter Verwendung eines Mittelwerartikulators
Erläuterungen zur Abrechnung
Sind Halte- und/oder Stützvorrichtungen sowie weitere Funktionsaufbisse erforderlich, können diese zusätzlich abgerechnet werden.
Die L-Nr. 403 0 ist je Aufbissbehelf abrechenbar.
Erneuerungen und Erweiterungen von Prothesenzähnen an der zum Aufbissbehelf umgearbeiteten Prothese sind mit der L-Nr. 403 0 nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 403 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das Umarbeiten einer vorhandenen Prothese oder eines bereits vorhandenen Aufbissbehelfs zum Aufbissbehelf mit adjustierter Oberfläche geschieht in der Regel durch Auftragen von Kaltpolymerisat auf die jeweiligen Okklusalflächen.
Hierzu ist als Voraussetzung die Registrierung der gewünschten neuen Bisslage und nachfolgend das Einstellen in Mittelwertartikulator (L-Nr. 012 0) erforderlich.
Falls gleichzeitig eine Instandsetzung/Erweiterung der Prothese oder eines bereits vorhandenen Aufbissbehelfs erfolgt, sind die hierfür notwendigen Leistungspositionen zusätzlich ansetzbar („Grundeinheit“, „Leistungseinheiten“, „Klammern“ etc.).
Leistungsanwendung
Die L-Nr. 403 0 ist berechnungsfähig für
– 
das Umarbeiten einer Prothese zum adjustierten Aufbissbehelf, je Prothese,
– 
das Adjustieren eines vorhandenen nicht adjustierten Aufbissbehelfs, je Aufbissbehelf,
– 
das Neuadjustieren eines vorhandenen adjustierten Aufbissbehelfs, je Aufbissbehelf,
jeweils unter Verwendung eines Mittelwertartikulators.
Eine Okklusionserhöhung an getragenen Prothesen durch PMMA‐Kunststoffe kann nicht mit L‐Nr. 802 4 abgerechnet werden.
Soweit gleichzeitig weitere Funktionen erfolgen sollen, können zusätzlich „Führungselemente“ bzw. „Funktionsaufbisse“ (z. B. zum Zwecke der Front-/Eckzahnführung) auf die Okklusalfläche aufgebaut werden; hierfür ist die L-Nr. 710 0 „Aufbiss“ (1 × je Kieferhälfte oder Frontzahngebiet) anzusetzen.
