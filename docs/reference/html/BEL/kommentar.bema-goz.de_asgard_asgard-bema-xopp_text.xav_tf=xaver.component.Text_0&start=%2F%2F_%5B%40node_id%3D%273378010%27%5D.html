BEL-L-Nr.Leistungsinhalt
103 3
Weitere Maßnahme bei Krone/Brückenglied:
Stiftaufbau in vorhandene Krone einarbeiten
Kurztext laut Anlage 2
103 3Stiftaufbau einarbeiten
Erläuterungen zum Leistungsinhalt
Gegossener Stiftaufbau aus Metall in eine vorhandene Krone oder Primärkrone einarbeiten.
Erläuterungen zur Abrechnung
—
▶ Kommentar zur BEL-L-Nr. 103 3
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das Einarbeiten eines Stiftaufbaus nach der L-Nr. 103 3 in eine vorhandene Krone oder Primärkrone dient dem Zweck, dass diese Krone wiederverwendet werden kann. Hierzu ist es erforderlich, dass der Stiftaufbau passgenau in den ursprünglich vom Zahnstumpf ausgefüllten Innenraum der Krone modelliert, gegossen und sodann eingearbeitet wird.
Leistungsanwendung
Zusätzliche Leistung zur L-Nr. 105 0 zum Erhalt der vorhandenen Krone/Primärkrone.
