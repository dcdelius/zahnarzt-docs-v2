▶ Kommentar zur BEL-L-Nr. 733 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der Begriff „Feder offen“ ist ein Sammelbegriff für alle einseitig verankerten Federn wie z. B. Protrusionsfeder, Retrusionsfeder („Rückholfeder“), Interdentalfeder, gekreuzte Feder, auch für den aktiven Dorn oder Sporn.
Die Feder ist ein sehr vielseitig einsetzbares orthodontisches Hilfsmittel zur Einzelzahn- oder Sektorenbewegung. Durch eine Feder können sowohl Druck- als auch Zugkräfte entwickelt werden.
Wird eine Feder angelötet, so ist hierfür die L-Nr.
744 0 
Metallverbindung (KFO)
zusätzlich abrechenbar.
