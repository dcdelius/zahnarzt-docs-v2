Erläuterungen zur Abrechnung
Die L-Nr. 301 0 ist als Grundeinheit für die Aufstellung von Konfektionszähnen auf Wachsbasis, Kunststoffbasis oder Metallbasis unter Verwendung eines Mittelwertartikulators abrechenbar.
▶ Kommentar zur BEL-L-Nr. 301 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 301 0 deckt zum Teil die vorbereitenden und begleitenden Leistungen bei der Aufstellung von konfektionierten Zähnen sowohl auf eine Wachs-/Kunststoffbasis als auch eine Metallbasis ab.
Grundsätzliche Voraussetzung für eine Aufstellung ist das Einstellen der Modelle in einen Mittelwertartikulator. „Höherwertige“ Artikulatoren etc. sind nicht Bestandteil der vertragszahnärztlichen Versorgung.
Die Aufstellung Grundeinheit ist erstens in Verbindung mit der L-Nr. 302 0 „Aufstellung auf Wachsbasis, je Zahn“ oder der L-Nr. 303 0 „Aufstellung auf Metallbasis, je Zahn“ ansetzbar, wird also durch Hinzufügen der jeweiligen Anzahl der L-Nrn. 302 0/303 0 zur vollständigen Aufstellung.
Zweitens ist die L-Nr. 301 0 auch dann ansetzbar, wenn z. B. die fehlenden Zähne nur durch die L-Nr. 383 0 „Herstellung eines Zahnes aus zahnfarbenem Kunststoff“ ersetzt werden.
Die L-Nr. 301 0 ist also mehr eine abrechnungstechnische als eine zahntechnische Positon, da sie insbesondere dazu dient, den vorbereitenden und begleitenden Aufwand auf die unterschiedliche Zahl der zu ersetzenden Zähne zu verteilen.
Aufstellungen zur Anprobe sollten grundsätzlich auf einer Kunststoff- oder Metallbasis erfolgen, da eine in die Mundhöhle des Patienten eingeführte Wachsbasis nicht ausreichend verwindungssteif ist.
Leistungsanwendung
Neuanfertigung einer partiellen oder totalen Prothese, auch mit Metallbasis.
Nicht abrechenbar, wenn die konfektionierten Zähne im Zusammenhang mit einer Schiene (L-Nrn. 401 0, 402 0, 404 0) aufgestellt werden.
