Erläuterungen zum Leistungsinhalt
Remontieren eines kieferorthopädischen Gerätes, z. B. Crozat, Retainer, Quad-Helix
Erläuterungen zur Abrechnung
Die L-Nr. 870 0 ist je remontiertem kieferorthopädischen Gerät einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 870 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 870 0 „Remontieren eines Gerätes ohne Kunststoffbasis“ findet dann Anwendung, wenn ein kieferorthopädisches Einzelkiefergerät ohne Kunststoffbasis wie z. B. Crozat-Gerät, Quad-Helix, Retainer etc. durch „Verbiegen“ der Bögen oder Einzelelemente unbrauchbar geworden ist und durch „Nacharbeit“ seine Funktion wieder zurückerlangt.
Müssen im Zuge der „Wiederaufpassungsmaßnahme auf das neue Modell“ Lötungen vorgenommen werden, sind diese Leistungen zusätzlich nach der L-Nr. 
744 0 
Metallverbindung (KFO)
ansetzbar.
Leistungsanwendung
Wiederherstellen der Funktion eines Einzelkiefergerätes ohne Kunststoffbasis.
