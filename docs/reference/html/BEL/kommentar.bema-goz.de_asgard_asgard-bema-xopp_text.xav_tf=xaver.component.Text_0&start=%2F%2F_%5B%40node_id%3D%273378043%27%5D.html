Erläuterungen zum Leistungsinhalt
Gegossene Rückenschutzplatte für Verblendung, auch mit Kaufläche.
Erläuterungen zur Abrechnung
Die L-Nr. 208 1 ist bei ungünstigen Biss- und Okklusionsverhältnissen, einzeln stehenden Zähnen oder über einem Sekundärteil eines Kugelknopfankers abrechenbar.
Neben der L-Nr. 208 1 sind die L-Nrn. 302 0, 303 0 und 362 0 nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 208 1
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die Rückenschutzplatte ist ein brückengliedartiges, mit einer Metallbasis (L-Nr. 201 0) oder einer Schiene verbundenes Gerüst zur Aufnahme einer Verblendung.
Die Verblendung einer Rückenschutzplatte erfolgt nach der unter der L-Nr. 160 0 oder 164 0 aufgeführten Leistung; ggf. kann hier – insbesondere bei einzeln stehenden Zähnen, die unter Zuhilfenahme einer Rückenschutzplatte ersetzt werden – zusätzlich zur L-Nr. 160 0 die L-Nr. 161 0 bzw. zusätzlich zur L-Nr. 164 0 die L-Nr. 165 0 „Zahnfleisch Komposite“ anfallen.
Wird eine Rückenschutzplatte als Einzelleistung, also nicht in direkter Verbindung mit einem gegossenen Basisteil (L-Nr. 806 0), nachträglich an eine Metallbasis angelötet, so ist für diese Lötung die L-Nr. 807 0 anzusetzen, ferner für die eigentliche Wiederherstellungs-/Erweiterungsmaßnahme die L-Nrn. 801 0 + 802 6/861 0 + 802 6.
Leistungsanwendung
Einzeln stehende Zähne sowie über Sekundärteil eines Kugelknopfankers.
Eine Rückenschutzplatte zieht die Verblendung (Kunststoffverblendung – L-Nr. 160 0 oder, qualitativ deutlich besser, Komposite-Verblendung – L-Nr. 164 0) nach sich; für den auf diese Weise zu ersetzenden Zahn sind also die L-Nrn. 208 1 + 160 0/208 1 + 164 0, nicht jedoch die L-Nrn. 302 0, 303 0, 362 0 abzurechnen.
Die L-Nr. 212 0 ist für eine nachträglich gegossene Rückenschutzplatte nicht abrechenbar.
