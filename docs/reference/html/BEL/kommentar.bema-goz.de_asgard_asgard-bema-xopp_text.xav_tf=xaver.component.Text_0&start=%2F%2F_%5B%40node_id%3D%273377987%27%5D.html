Basis aus Kunststoff (ohne Bisswall)

Kurztext laut Anlage 2
021 2Funktionslöffel
Erläuterungen zum Leistungsinhalt
Funktionsabdrucklöffel aus Kunststoff für einen zahnlosen Kiefer oder bei stark reduziertem Restgebiss.
Erläuterungen zur Abrechnung
Die L-Nr. 021 2 ist bei einem zahnlosen Kiefer oder bei einem Kiefer mit einem Restzahnbestand von bis zu drei Zähnen abrechenbar.
▶ Kommentar zur BEL-L-Nr. 021 2
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der Funktionslöffel wird aus selbsthärtendem Kunststoff individuell hergestellt und dient der Funktions-Abdrucknahme bei einem unbezahnten, ggf. auch teilbezahnten Kiefer.
Leistungsanwendung
Der Funktionslöffel kann im Falle der gleichzeitig mit der Abdrucknahme vorgenommenen Bissregistrierung um die L-Nr. 022 0 „Bisswall“ ergänzt werden.
