Die L-Nr. 362 0 ist entsprechend der Zahl der aufgestellten konfektionierten Zähne abrechenbar.
▶ Kommentar zur BEL-L-Nr. 362 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 362 0 deckt den Aufwand ab, der mit dem „Fertigstellen“, d. h. festem Verbinden des Einzelzahnes mit dem Kunststoffsattel, verbunden ist.
Wird bei der Fertigstellung ein Zahn zahnfarben hinterlegt, so sind sowohl die L-Nrn. 302 0/303 0 (für die Aufstellung dieses Zahnes) und 362 0 als auch die hierbei verwendeten Materialkosten „Konfektionszahn“ anzusetzen (siehe hierzu Kommentar zur L-Nr. 384 0!).
Die L-Nr. 362 0 ist auch ansetzbar für konfektionierte Zähne, die an eine Schiene oder ein kieferorthopädisches Gerät angefügt werden.
Leistungsanwendung
Ergänzende Leistung zur L-Nr. 361 0; sie wird unter Berücksichtigung ihrer jeweiligen Menge zur „Gesamtleistung Fertigstellung“. Auch abrechenbar bei aus Kunststoff hergestellten Schienen („Aufbissbehelfen“) und ggf. neben der L-Nr. 701 0.
