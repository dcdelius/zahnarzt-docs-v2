Fertigstellung einer Prothese, Grundeinheit, je Kiefer
Kurztext laut Anlage 2
361 0Fertigstellung Grundeinheit
Erläuterungen zum Leistungsinhalt
Grundeinheit der Fertigstellung einer Prothese mit Kunststoff- oder Metallbasis unter Verwendung eines Mittelwertartikulators, einschließlich des ggf. notwendigen Abdeckens von Kieferteilen und/oder des Vornehmens von Radierungen.
Erläuterungen zur Abrechnung
—
▶ Kommentar zur BEL-L-Nr. 361 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 361 0 setzt die vorherige Aufstellung (L-Nr. 301 0) voraus und beinhaltet alle diejenigen „allgemeinen“ Leistungen, die für die Fertigstellung einer reinen Kunststoffprothese oder einer Prothese mit Metallbasis erforderlich sind, wie z. B. Ausmodellieren, Einbetten, Entfernen des Wachses, Isolieren der Gipsform, Einbringen des Kunststoffes, Polymerisieren etc.
Auch die Fertigstellung erfordert die Anwendung eines Mittelwertartikulators.
Sie ist erstens in Verbindung mit der L-Nr. 362 0 „Fertigstellen je Zahn“ ansetzbar, wird also durch Hinzufügen der jeweiligen Anzahl der L-Nr. 362 0 zur vollständigen Fertigstellung.
Zweitens ist die L-Nr. 361 0 auch dann abrechenbar, wenn z. B. die fehlenden Zähne nur durch die L-Nr. 383 0 „Herstellung eines Zahnes aus zahnfarbenem Kunststoff“ ersetzt werden.
Nicht zum Leistungsinhalt der L-Nr. 361 0 gehören Leistungen wie Einarbeiten eines Netzes, Gitters, Drahtes, Bügels, Federpaares, Magnetpaares, einer Beschwerungseinlage, Saugkammer oder Metallfacette, transparente Gaumenplatte, Prothese aus transparentem Kunststoff, Schwerkunststoff oder Kautschuk, Spezialpressverfahren, Charakterisieren einer Basis, Remontage Prothetik, Reokkludieren einer Prothese, selektives Einschleifen Prothetik, Konditionieren eines Modellgussteiles.
Die Herstellung (Fertigstellung) einer Prothese unter Zuhilfenahme von Sonderkunststoff (= Sondermaterial) ist unter der L-Nr. 382 2 Verarbeitung von Sonderkunststoff zusätzlich abrechenbar, wenn die hierfür erforderlichen Voraussetzungen erfüllt sind (nachgewiesene Materialunverträglichkeit).
Leistungsanwendung
Zweiter und abschließender Teil der Neuanfertigung einer totalen oder partiellen Prothese, auch mit Metallbasis.
Nicht abrechenbar, wenn die konfektionierten Zähne im Zusammenhang mit einer Schiene (L-Nrn. 401 0, 402 0, 404 0) fertiggestellt werden.
