Erläuterungen zur Abrechnung
Kann bei einer Unterkiefer-Modellgussprothese kein Sublingualbügel angefertigt werden, sind neben der L-Nr. 201 0 die L-Nr. 202 1 (fortlaufende Klammer) sowie die L-Nrn. 202 5 und 208 3 abrechenbar.
Für die Herstellung eines gegossenen Retentionsgitters oder eines gegossenen Retentionsbügels bei einer schleimhautgetragenen Deckprothese ist die L-Nr. 201 0 abrechenbar.*
▶ Kommentar zur BEL-L-Nr. 201 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Eine Metallbasis wird überwiegend im Einstück-Modellgussverfahren aus einer mundbeständigen Nichtedelmetall-Legierung (Kobalt-Chrom-Legierungen) unter Zuhilfenahme eines „Einbettmassemodells“ zusammen mit Retentionen zur Aufnahme der Ersatzzahn tragenden Kunststoffsättel hergestellt.
Eine Metallbasis kann auch, z. B. im unbezahnten Unterkiefer, zum Zwecke der völligen Ummantelung mit Kunststoff gefertigt werden; diese Methode erleichtert eine evtl. später notwendig werdende Unterfütterung mit hartem oder weichem Kunststoff.
Die Gestaltung ist abhängig von der Verteilung der Restzähne bzw. Restzahngruppen, Schaltlücken oder Zahnreihenverkürzungen. Dadurch ist eine Vielzahl von Formvarianten möglich: als totale Basis, als partielle Basis mit gegossenen Halte- und Stützvorrichtungen oder als Basis mit Rückenschutzplatten oder Kragenfassungen.
Kann z. B. wegen medizinischer Indikation (hoher Mundboden, parodontal geschädigtes Restgebiss) kein Sublingualbügel hergestellt werden, wird die Metallbasis in Form einer über die Lingualflächen der unteren Frontzähne verlaufenden fortlaufenden Klammer gefertigt (auch „Basler“-/„Tübinger“-Schiene genannt).
In diesem Falle stellt die Metallbasis die „Grundeinheit“ dar, die durch zusätzliche Leistungen wie fortlaufende Klammern nach der L-Nr. 202 5, Krallen nach der L-Nr. 202 5 oder/und Metallkauflächen nach der L-Nr. 208 3 ergänzt wird.
Bei einseitigen Freiendprothesen kann die Herstellung eines gegossenen Retentionsgitters oder eines gegossenen Retentionsbügels nach der L-Nr. 201 0 angezeigt sein.
Das Konditionieren der Sättel zum Zwecke einer spaltfreien Metall-/Kunststoffverbindung gehört nicht zum Leistungsumfang der L-Nr. 201 0.
Leistungsanwendung
Die L-Nr. 201 0 ist abrechnungsfähig für die Herstellung einer Modellgussprothese sowie für ein gegossenes Retentionsgitter oder einen gegossenen Retentionsbügel bei einer schleimhautgetragenen Deckprothese. Zusätzlich können erforderliche Halte- und Stützvorrichtungen, Rückenschutzplatten, Metallzähne oder -kauflächen abgerechnet werden.
Eine Berechnung der L-Nr. 201 0 ist ausgeschlossen für Retentionen an teleskopierenden Sekundärkronen sowie für die Erweiterung einer vorhandenen Modellgussbasis (vgl. L-Nr. 806 0).
