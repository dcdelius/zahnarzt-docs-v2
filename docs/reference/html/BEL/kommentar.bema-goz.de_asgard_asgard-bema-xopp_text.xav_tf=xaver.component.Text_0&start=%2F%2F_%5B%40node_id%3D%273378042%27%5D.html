▶ Kommentar zur BEL-L-Nr. 205 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die nach Lehrbuch-Definition eigentliche Bonwillklammer umfasst zwei nebeneinander stehende Zähne und besteht aus vier Klammerarmen, die beim vorderen Zahn nach mesial und beim hinteren Zahn nach distal geführt werden, sowie zwei Auflagen. Werden weitere Auflagen gefertigt, sind diese nicht Bestandteil dieser Klammer und können jeweils mit der L-Nr. 202 7 (Auflage) berechnet werden.
Bonwillklammern werden zwar überwiegend sattelfern mit der Metallbasis verbunden, dennoch kann das hierfür notwendige Verbindungselement (Ney-Stiel) nicht gesondert berechnet werden.
Durch eine Änderungsvereinbarung zwischen dem Verband Deutscher Zahntechniker-Innungen (VDZI) und dem Spitzenverband Bund der Krankenkassen (GKV-Spitzenverband) vom 10.10.2014 wurde festgelegt, dass der Ney-Stiel (L-Nr. 202 6) Bestandteil der L-Nr. 205 0 (Bonwillklammer) ist.
Die L-Nr. 202 6 „Ney-Stiel“ ist also nun nicht mehr bei einer Bonwillklammer zusätzlich abrechenbar.
Wird eine Leistung nach der Nr. 205 0 nicht im Zusammenhang mit einer Metallbasis (L-Nr. 201 0), sondern einzeln gefertigt, so wird zusätzlich die L-Nr. 212 0 „Zuschlag für einzeln gegossene Klammer(n)“ unter Beachtung von deren Erläuterungen abrechenbar.
Die im Rahmen einer Wiederherstellungs- oder Erweiterungsmaßnahme neu gefertigte Haltevorrichtung löst bei deren Anlöten an die vorhandene Metallbasis neben der L-Nr. 212 0 und der L-Nr. 802 5 „Leistungseinheit Klammer einarbeiten“ die L-Nr. 807 0 „Metallverbindung bei Wiederherstellung/Erweiterung“ aus.
Leistungsanwendung
Überwiegend im Modellgussverfahren hergestellte „Klammer“ zur Befestigung des herausnehmbaren Zahnersatzes an den Restzähnen.
