Erläuterungen zum Leistungsinhalt
Hierzu zählen die einarmige Klammer, die Inlayklammer, die fortlaufende Klammer (je Zahn) und die Bonyhardklammer.
Erläuterungen zur Abrechnung
—
▶ Kommentar zur BEL-L-Nr. 202 1
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Bei der Neufassung der Klammern im BEL wurden die einarmige Klammer, die Inlayklammer, die fortlaufende Klammer je Zahn und die Bonyhardklammer zu einer Position unter der L-Nr. 202 1 zusammengefasst.
Das Einarbeiten der Haltevorrichtung – z. B. durch Einschleifen des angrenzenden künstlichen Zahnes – ist Leistungsinhalt der L-Nr. 202 1/303 0.
Wird eine Leistung nach der L-Nr. 202 – nicht im Zusammenhang mit einer Metallbasis (L-Nr. 201 0), sondern einzeln gefertigt, so wird zusätzlich die L-Nr. 212 0 „Zuschlag für einzeln gegossene Klammer(n)“ unter Beachtung von deren Erläuterungen abrechenbar.
Die im Rahmen einer Wiederherstellungs- oder Erweiterungsmaßnahme neu gefertigte Haltevorrichtung löst bei deren Anlöten an die vorhandene Metallbasis neben der L-Nr. 212 0 und der L-Nr. 802 5 „Leistungseinheit Klammer einarbeiten“ die L-Nr. 807 0 „Metallverbindung bei Wiederherstellung/Erweiterung“ aus.
 
Leistungsanwendung
Überwiegend im Modellgussverfahren hergestellte „Klammer“ zur Befestigung des herausnehmbaren Zahnersatzes an den Restzähnen.
