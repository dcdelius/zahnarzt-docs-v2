▶ Kommentar zur BEL-L-Nr. 731 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zusätzlich zu dem Leistungsinhalt und den Aufgaben, die der Labialbogen nach der L-Nr. 730 0 enthält und zu erfüllen hat, werden an den modifizierten Labialbogen weitere Anforderungen gestellt:
Mittels seiner zusätzlichen („mehr als zwei“) Schlaufen sollte er neben seiner Funktion als Fixierungs- und „Abschirmungselement“ auch noch Einzelzahn-Bewegungsaufgaben wahrnehmen.
Seine Herstellung ist deshalb deutlich aufwendiger.
Der „Labialbogen modifiziert“ nach der L-Nr. 731 0 bezieht sich auf einen Kiefer.
Leistungsanwendung
Orthodontisches Hilfsmittel zur Abschirmung gegen den Lippendruck, als „Fixierungselement“ für die nicht zu bewegenden Zähne sowie mittels der zusätzlichen Schlaufen als Bewegungselement bei protrudierten Zähnen.
