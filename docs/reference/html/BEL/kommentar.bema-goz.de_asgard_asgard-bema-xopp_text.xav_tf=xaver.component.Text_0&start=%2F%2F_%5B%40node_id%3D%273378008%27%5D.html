103 1 Weitere Maßnahme bei Krone/Brückenglied:
Vorbereiten einer Krone/eines Brückengliedes zur Aufnahme einer Halte- und/oder Stützvorrichtung
BEL-L-Nr.Leistungsinhalt
103 1
Weitere Maßnahme bei Krone/Brückenglied:
Vorbereiten einer Krone/eines Brückengliedes zur Aufnahme einer Halte- und/oder Stützvorrichtung
Kurztext laut Anlage 2
103 1Vorbereiten Krone
Erläuterungen zum Leistungsinhalt
—
Erläuterungen zur Abrechnung
Die L-Nr. 103 1 ist für das Vorbereiten einer neu zu fertigenden Krone oder eines Brückengliedes für eine Halte- und/oder Stützvorrichtung abrechenbar.
Die L-Nr. 103 1 ist nur einmal je Krone oder Brückenglied abrechenbar.
Neben der L-Nr. 103 1 ist die L-Nr. 103 2 für dieselbe Krone oder dasselbe Brückenglied nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 103 1
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 103 1 ist eine ergänzende Leistung zu allen Arten von Kronen oder Brückengliedern. Ihr Sinn besteht darin, eine Krone/ein Brückenglied so zu modellieren, dass eine nachträglich um die Krone/das Brückenglied zu führende Klammer oder eine Stützvorrichtung eine optimale Funktion erfüllen kann.
Leistungsanwendung
Der Hinweis in den Erläuterungen zur Abrechnung besagt zwar, dass neben der L-Nr. 103 1 die L-Nr. 103 2 nicht abrechenbar ist.
Wird jedoch am gleichen Zahn, für den die L-Nr. 103 1 zur Anwendung kommt, ein gefrästes Lager zur Aufnahme eines Schubverteilungsarmes gefertigt, so ist diese Leistung neben der L-Nr. 103 1 unter der L-Nr. 136 0 „Gefrästes Lager für Schubverteilungsarm“ abrechenbar.
