155 0Konditionierung je Zahn/Flügel
Erläuterungen zum Leistungsinhalt
Konditionierung einer Metallfläche zur Aufnahme einer vestibulären Verblendung mit Komposit oder zur Vorbereitung einer adhäsiven Befestigung.
Erläuterungen zur Abrechnung
Die L-Nr. 155 0 ist je Flügel für Adhäsivbrücke (L-Nr. 102 3) und bei Verblendungen je Krone, Brückenglied oder Rückenschutzplatte nach L-Nr. 164 0 abrechenbar.
Bei der L-Nr. 404 0 – semipermanente Schiene – ist die L-Nr. 155 0 je Zahn abrechenbar.
▶ Kommentar zur BEL-L-Nr. 155 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die auch unter dem Begriff „Silanisieren“ bekannte Konditionierung dient zum einen dazu, eine absolut spaltfreie Verbindung ohne mechanische Retentionen zwischen einer Metalloberfläche und dem aufzubringenden Verblendmaterial Komposite zu ermöglichen.
Zum anderen ist sie eine vorbereitende Maßnahme, um die Flügel einer Adhäsivbrücke oder eine semipermanente Schiene im Munde des Patienten „verkleben“ zu können.
Das Konditionieren geschieht durch das Aufbringen der Siliziumdioxydschicht auf die zu verblendende oder zu „verklebende“ Gerüstfläche.
Um einen optimalen Verbund zu erreichen, muss das Gerüst absolut fettfrei gestrahlt sein; hierzu ist ein nur für diesen Einsatz reserviertes Strahlgerät und spezielles Strahlmittel unabdingbare Voraussetzung.
Durch die Konditionierung wird eine feste Verbindung zwischen zwei unterschiedlichen Komponenten (Materialien) erreicht.
Leistungsanwendung
Je Krone/Brückenglied/teleskopierende Sekundärkrone/Rückenschutzplatte/Zahn bei semipermanenter Schiene abrechenbare vorbereitende Leistung für Verblendungen mit Komposite oder zur Befestigung von Adhäsivbrücken im Munde des Patienten.
