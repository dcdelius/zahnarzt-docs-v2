021 1
Basis aus Kunststoff (ohne Bisswall)
– Individueller Löffel
Kurztext laut Anlage 2
021 1Individueller Löffel
Erläuterungen zum Leistungsinhalt
Individueller Abdrucklöffel aus Kunststoff für vollbezahnten oder teilbezahnten oder zahnlosen Kiefer, wenn eine Funktionsabformung nicht notwendig oder möglich ist.
Erläuterungen zur Abrechnung
Das Doppelabdruckverfahren mit einem Konfektionslöffel erfüllt nicht den Leistungsinhalt.
▶ Kommentar zur BEL-L-Nr. 021 1
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der individuelle Löffel wird in der Regel aus selbsthärtendem Kunststoff hergestellt.
Leistungsanwendung
Der individuelle Löffel ist ein Hilfsmittel zur Abdrucknahme. Er kann ggf. ergänzt werden um die L-Nr. 022 0 „Bisswall“, wenn gleichzeitig mit der Abdrucknahme eine Bissregistrierung vorgenommen werden soll.
