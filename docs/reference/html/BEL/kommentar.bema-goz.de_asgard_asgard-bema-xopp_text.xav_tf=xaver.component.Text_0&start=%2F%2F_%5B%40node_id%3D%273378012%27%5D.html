Erläuterungen zum Leistungsinhalt
Gegossener Stiftaufbau (bestehend aus Wurzelstift und Stumpfaufbau) aus Metall nach indirektem Verfahren.
Pin setzen, je Segment, auch im Bereich des Kieferkammes und des an die Versorgung angrenzenden Zahnes,
Sägeschnitt, Segment beschleifen und vorbereiten.
Präparationsgrenze darstellen, ggf. ausblocken, versiegeln oder lackieren.
Ggf.
Einzelstumpf aus Superhartgips oder aus Kunststoff,
Stumpf für reponierte Elemente einschließlich Reponieren.
Erläuterungen zur Abrechnung
Die L-Nr. 105 0 ist für denselben Zahn nicht neben der L-Nr. 101 3 abrechenbar.
▶ Kommentar zur BEL-L-Nr. 105 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der Stiftaufbau nach der L-Nr. 105 0 wird im indirekten Verfahren, d. h. nach Abdrucknahme und Modell- und Stumpfherstellung gefertigt.
Eine besondere Situation liegt vor, wenn Stiftaufbauten für mehrwurzelige Zähne benötigt werden. Falls die Wurzeln eines Zahnes stark kon- oder divergieren, kann ein einzelner zusammenhängender Stiftaufbau nicht inkorporiert werden; dann müssen für einen Zahn mehrere Stiftaufbauten meist nacheinander gefertigt werden.
Leistungsanwendung
Vorbereitende Maßnahme zur nachträglichen Aufnahme einer Krone oder Primärkrone.
Werden für einen Zahn mehrere Stiftaufbauten benötigt, wird empfohlen, diese besondere Situation bei der Abrechnung zu vermerken.
Das Einarbeiten eines Stiftaufbaus nach der L-Nr. 105 0 in eine vorhandene Krone oder Primärkrone wird nach der L-Nr. 103 3 abgerechnet.
