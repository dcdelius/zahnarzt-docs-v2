▶ Kommentar zur BEL-L-Nr. 802 7
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zusätzliche Einzelleistung bei einer Instandsetzung und/oder Erweiterung einer Basis aus Metall.
Das Entfernen und Wiederbefestigen eines Prothesensattels ist zumindest immer dann vonnöten, wenn in seiner unmittelbaren Nähe die Metallbasis wegen eines Lötvorganges erhitzt wird.
Leistungsanwendung
Abrechenbar neben der Grundeinheit nach der L-Nr. 
801 0 
Grundeinheit für Instandsetzung und/oder Erweiterung einer Prothese,
einmal je erbrachte Einzelleistung.
Eigenständige Leistung bei Lötung an Metallbasen.
Auch abrechenbar aus anderweitigen Gründen (z. B. gewünschte Veränderung der Bisslage).
