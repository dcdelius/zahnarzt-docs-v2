Individueller Löffel Unterkieferprotrusionsschiene
Kurztext laut Anlage 2
021 7Individueller Löffel UKPS
Erläuterungen zum Leistungsinhalt
Individueller Abdrucklöffel aus Kunststoff für vollbezahnten oder teilbezahnten oder zahnlosen Kiefer zur Herstellung einer Unterkieferprotrusionsschiene.
Erläuterungen zur Abrechnung
Das Doppelabdruckverfahren mit einem Konfektionslöffel erfüllt nicht den Leistungsinhalt der L-Nr. 021 7.
▶ Kommentar zur BEL-L-Nr. 021 7
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Im Rahmen der Herstellung einer UKPS ist die präzise Abformung beider Kiefer als Grundlage für eine optimale Passform und Funktion der Schienen notwendig. Der dazu als Hilfsmittel eingesetzte individuelle Löffel wird in der Regel aus selbsthärtendem Kunststoff (Autopolymerisat) auf einem Vormodell hergestellt. Vorteil eines solchen individuellen Abdrucklöffels ist, dass er speziell der Kieferform des Patienten angepasst wird und man gleichzeitig die gewünschte gleichmäßige Schichtdicke des Abformmaterials erzielen kann.
Leistungsanwendung
Der individuelle Löffel ist ein Hilfsmittel zur Abdrucknahme für die Fälle, in denen eine Abformung der Zahnbögen mit einem konfektionierten Löffel für die anzufertigende Unterkieferprotrusionsschiene nicht ausreicht.
Zusätzlich ist für das Modell, das zur Herstellung des individuellen Abdrucklöffels benötigt wird, die L-Nr. 001 5 (Modell UKPS) abrechnungsfähig.
Für das Individualisieren eines konfektionierten Löffels können die Materialkosten zusätzlich abgerechnet werden.
