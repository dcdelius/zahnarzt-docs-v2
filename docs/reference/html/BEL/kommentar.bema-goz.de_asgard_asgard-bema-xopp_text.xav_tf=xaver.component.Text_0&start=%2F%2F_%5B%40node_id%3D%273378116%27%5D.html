806 0Gegossenes Basisteil
Erläuterungen zum Leistungsinhalt
Die L-Nr. 806 0 beinhaltet die Herstellung eines gegossenen Basisteils zur Erweiterung einer vorhandenen Basis sowie das Einarbeiten und die Metallverbindung ggf. einschließlich eines Duplikatmodells aus Einbettmasse.
Erläuterungen zur Abrechnung
Die L-Nr. 806 0 ist je Basisteil abrechenbar.
Neben der L-Nr. 806 0 ist die L-Nr. 201 0 nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 806 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das gegossene Basisteil wird im Modellgussverfahren unter Zuhilfenahme eines Duplikatmodells aus feuerfester Masse („Einbettmasse“) aus einer mundbeständigen Nichtedelmetall-Legierung (Kobalt-Chrom-Legierung) hergestellt.
Leistungsinhalt der L-Nr. 806 0 sind sowohl die im Kieferkammbereich des gegossenen Basisteils angebrachten Retentionen wie auch das Anlöten des Basisteils an die vorhandene Metallbasis bzw. an das/die Sekundärteil(e) der teleskopierenden Krone(n).
Das gegossene Basisteil ersetzt zur Erweiterung einer vorhandenen Basis ein fehlendes Teil einer Metallbasis in der Regel so, dass es mit einem Sattel zur Aufnahme zu ersetzender Zähne ausgestattet ist. Es kann ferner – z. B. auch ohne Sattel – die Verbindung zwischen der vorhandenen Metallbasis und neu anzufügenden Verbindungsvorrichtungen (in der Regel teleskopierende Kronen), Halte- und/oder Stützvorrichtungen und dergleichen im Rahmen umfangreicher Reparaturmaßnahmen oder Erweiterungen herstellen.
Leistungsanwendung
Abrechenbar einmal je Basisteil.
Eine Abrechnung der L-Nr. 806 0 ist für denselben Kieferbereich ausgeschlossen neben:
– 
L-Nr. 201 0 (Metallbasis)
– 
L-Nr. 303 0 (Aufstellung auf Metallbasis, je Zahn)
– 
L-Nr. 804 0 (Retention, gegossen)
– 
L-Nr. 807 0 (Metallverbindung bei Instandsetzung/Erweiterung)
Die L-Nr. 806 0 ist nicht abrechnungsfähig für die Herstellung eines gegossenen Retentionsgitters oder -bügels bei einer schleimhautgetragenen Deckprothese (L-Nr. 201 0) oder für eine gegossene Retention (L-Nr. 804 0).
