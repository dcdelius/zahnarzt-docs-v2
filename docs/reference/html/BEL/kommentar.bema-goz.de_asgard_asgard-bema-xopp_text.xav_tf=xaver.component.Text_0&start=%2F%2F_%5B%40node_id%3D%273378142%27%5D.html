▶ Kommentar zur BEL-L-Nr. 970 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 970 0 beschreibt den Herstellungsaufwand, der bei der Verarbeitung von Nichtedelmetall – abweichend von der Verarbeitung von Edelmetall-Legierungen – zusätzlich anfällt.
In den Erläuterungen zur Abrechnung sind diejenigen Leistungen aufgeführt, die dann, wenn sie aus einer Nichtedelmetall-Legierung gefertigt wurden, je einmal den Leistungsansatz 970 0 auslösen.
Die L-Nr. 970 0 beschreibt nur den Aufwand für die Verarbeitung einer Nichtedelmetall-Legierung.
Leistungsanwendung
Nur abrechenbar, wenn die jeweilige Leistung aus einer Nichtedelmetall-Legierung gefertigt wurde.
