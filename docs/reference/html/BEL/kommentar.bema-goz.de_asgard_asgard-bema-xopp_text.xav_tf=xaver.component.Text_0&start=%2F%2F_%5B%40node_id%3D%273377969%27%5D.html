Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das Sägemodell wird auf zwei unterschiedliche Weisen hergestellt:
Das zweiphasig trennbar hergestellte Modell wird in zwei aufeinander folgenden Arbeitsgängen meist unter Verwendung farblich unterschiedlicher Gipse hergestellt. Zunächst wird der Zahnkranz (auch unter BEL-Nr. 006 0 aufgeführt) ausgegossen; in diesen werden die Führungsstifte (Dowel-Pins) an den Stellen, wo Segmente aus dem Sockel herausgenommen werden sollen, eingesetzt. Sodann wird der Sockel des Modells (auch unter BEL-Nr. 007 0 aufgeführt) hergestellt. Durch Sägeschnitte werden diejenigen Segmente, die aus dem Sockel herausnehmbar und wieder reponierbar sein sollen, aus dem Zahnkranz herausgesägt.
Das einphasig trennbare Modell wird mittels eines Sockelformers (z. B. Model-tray) in einem Arbeitsgang hergestellt. Durch Sägeschnitte werden die herausnehmbar gewünschten Teile getrennt; sie sind durch das Wiedereinfügen in den Sockelformer passgenau reponierbar.
Leistungsanwendung
Das Sägemodell findet als Träger der herausnehmbaren Stümpfe oder Segmente vorwiegend Anwendung bei allen Arten von Kronen, teleskopierenden Kronen oder Brücken.
Die jeweils benötigten Stümpfe sind in die Kronenpositionen integriert, so dass bei einer Regelversorgung keine gesonderte Berechnungsmöglichkeit besteht.
Als ergänzende Leistungen zum Sägemodell im Sinne einer qualitativ hochwertigen Versorgung kommen sowohl die Zahnfleischmaske als auch das Galvanisieren als dazu notwendige Leistungen zur Anwendung.
