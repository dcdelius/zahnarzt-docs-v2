BEL-L-Nr.Leistungsinhalt
163 8
Zahnfleisch aus Keramik bei Implantatversorgung
Kurztext laut Anlage 2
163 8Zahnfleisch Keramik bei Implantatv.
Erläuterungen zum Leistungsinhalt
Herstellen von Zahnfleischpartien aus Keramik zum Ausgleich von Alveolaratrophien, Kieferdefekten und Stellungsanomalien in Verbindung mit einer Verblendung.
Erläuterungen zur Abrechnung
Die L-Nr. 163 8 ist für das Herstellen von Zahnfleischpartien bei einer Krone nach L-Nr. 102 8 im Rahmen einer Versorgung nach Nr. 36 a der Zahnersatz-Richtlinie (zahnbegrenzte Einzelzahnlücke) abrechenbar.
Die L-Nr. 163 8 ist je Zahn einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 163 8
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Um bei einer Implantat-gestützten Einzelkrone einen gleichmäßigen Verlauf des Zahnfleischsaumes zu den Nachbarzähnen zu erzielen, ist es bei Vorliegen von Kieferdefekten jeglicher Art notwendig, die fehlende Kiefersubstanz durch künstliches Zahnfleisch auszugleichen.
Leistungsanwendung
Nur abrechenbar bei Keramikverblendung einer Implantat-gestützten Einzelkrone.
