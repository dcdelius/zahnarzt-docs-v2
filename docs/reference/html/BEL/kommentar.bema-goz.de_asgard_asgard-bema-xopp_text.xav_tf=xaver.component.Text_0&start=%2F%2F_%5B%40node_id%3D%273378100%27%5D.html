▶ Kommentar zur BEL-L-Nr. 743 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das Schloss, das Röhrchen, der Lückenhalter oder Lückendehner sind die unter der L-Nr. 743 0 aufgeführten Einzelelemente.
Diese Einzelelemente werden an einem Ankerband/einer Ankerkappe so positioniert, dass sie die ihnen zugeordnete Funktion erfüllen können. So müssen z. B. Röhrchen zur Aufnahme von Bögen so angebracht sein, dass der Bogen spannungsfrei in die Röhrchen eingeführt werden kann. Ebenso muss ein Schloss seine Funktion spannungsfrei erfüllen können.
Lückenhalter oder Lückendehner sind meist Stege, die zwischen zwei Ankerbändern/Ankerkappen eingefügt werden.
Lötungen sind nach der L-Nr. 744 0 aufzuführen.
Werden zur Einarbeitung von Einzelelementen Konfektionsfertigteile wie z. B. Röhrchen, Schlösser etc. verwendet, so sind die Materialkosten gesondert aufzuführen.
Leistungsanwendung
Hilfsmittel zur Verankerung bei festsitzend/herausnehmbaren oder festsitzenden Geräten.
