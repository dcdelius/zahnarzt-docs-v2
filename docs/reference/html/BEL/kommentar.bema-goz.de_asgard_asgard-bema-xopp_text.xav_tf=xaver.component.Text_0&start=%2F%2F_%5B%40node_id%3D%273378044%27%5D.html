Erläuterungen zur Abrechnung
Die L-Nr. 208 2 ist bei ungünstigen Biss- und Okklusionsverhältnissen oder für die Versorgung von verengten Einzelzahnlücken oder über einem Sekundärteil eines Kugelknopfankers abrechenbar.
Neben der L-Nr. 208 2 sind die L-Nrn. 302 0, 303 0 und 362 0 für den Metallzahn nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 208 2
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der Metallzahn ist ein vollständig aus Metall hergestellter, brückengliedartiger, mit der Metallbasis (L-Nr. 201 0) oder einer Schiene fest verbundener Ersatzzahn.
Wird ein Metallzahn als Einzelleistung, also nicht in direkter Verbindung mit einem gegossenen Basisteil (L-Nr. 806 0), nachträglich an eine Metallbasis angelötet, so ist für diese Lötung die L-Nr. 807 0 ansetzbar, ferner für die eigentliche Wiederherstellungs-/Erweiterungsmaßnahme die L-Nrn. 801 0 + 802 –/861 0 + 802 –.
Leistungsanwendung
Der Metallzahn findet im Seitenzahngebiet dann Anwendung, wenn aus Platz- oder sonstigen Gründen kein Konfektionszahn verwendet werden kann und auf eine Verblendung verzichtet werden soll.
