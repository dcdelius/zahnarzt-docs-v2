Erläuterungen zum Leistungsinhalt
Einarbeiten eines individuellen oder konfektionierten Befestigungselements zur Aufnahme eines Elements zur Begrenzung der Mundöffnung in die Basis einer Unterkieferprotrusionsschiene.
Erläuterungen zur Abrechnung
Die L-Nr. 520 0 ist je Unterkieferprotrusionsschiene viermal abrechenbar.
Die L-Nr. 520 0 ist auch für die Erneuerung eines Befestigungselements abrechenbar.
▶ Kommentar zur BEL-L-Nr. 520 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Gegenstand der L-Nr. 520 0 ist das Einarbeiten eines individuellen oder konfektionierten Mundöffnungsbegrenzungselements in die Basis einer Unterkieferprotrusionsschiene, um dem Patienten eine Mundöffnung im therapeutischen Rahmen zu ermöglichen.
So existieren Schienen-Varianten, bei denen die Befestigungspunkte im Oberkiefer distal und im Unterkiefer mesial liegen, sodass eine Begrenzung der Mundöffnung durch sogenannte Elastikketten erforderlich werden kann. Diese bestehen aus Silikon und werden jeweils im Ober- und Unterkiefer in gebogene Häkchen oder auch Knopfklammern eingehakt. Sie verhindern so eine zu große Mundöffnung (z. B. IST®-Gerät nach Hinz).
Leistungsanwendung
Die L-Nr. 520 0 ist nur bei Schienen abrechnungsfähig, bei denen nicht schon durch das Schienensystem (z. B. TAP®-Schiene oder Flossenschiene [z. B. SomnoDent®-Schiene]) eine Mundöffnungsbegrenzung vorgegeben ist.
Die Leistungsnummer kann sowohl für Neuanfertigungen als auch für Instandsetzungen bis zu viermal abgerechnet werden.
Die Materialkosten für „konfektionierte Mundöffnungsbegrenzungselemente“ (z. B. Elastikketten) sind gesondert abrechenbar.
