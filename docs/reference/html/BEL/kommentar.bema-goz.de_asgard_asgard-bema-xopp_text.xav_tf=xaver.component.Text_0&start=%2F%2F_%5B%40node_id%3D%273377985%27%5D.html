020 5 Vorbereiten einer Bissgabel Unterkieferprotrusionsschiene
BEL-L-Nr.Leistungsinhalt
020 5
Vorbereiten einer Bissgabel Unterkieferprotrusionsschiene
Kurztext laut Anlage 2
020 5Vorbereiten Bissgabel UKPS
Erläuterungen zum Leistungsinhalt
Vorbereiten einer Bissgabel zur Registrierung der Protrusion für eine Unterkieferprotrusionsschiene.
Erläuterungen zur Abrechnung
Die L-Nr. 020 5 ist für die Anfertigung einer UKPS einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 020 5
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zur Bestimmung einer reproduzierbaren Kieferrelation für die Startposition einer UKPS wird in der Regel als Hilfsmittel eine „Bissgabel“ benötigt, die aufgrund ihrer Möglichkeiten zur Justierung in allen drei Achsen eine Bestimmung der maximalen aktiven Protrusion und Retrusion sowie eine Registrierung der Kiefer zueinander reproduzierbar gestattet. Die Justierung mit dem Hilfsmittel gelingt entweder über additive und subtraktive Anpassungen oder über eine stufenlose Einstellvorrichtung in allen drei Achsen.
Leistungsanwendung
Unter der L-Nr. 020 5 wird das Vorbereiten (Beschickung) einer vorhandenen Bissgabel des Übertragungsbogens mit geeignetem Material (z. B. thermoplastische Massen wie Wachs und Compound oder Pasten) abgerechnet.
Die vorbereitende Leistung nach L-Nr. 020 5 kann einmal für eine Versorgung mit einer Unterkieferprotrusionsschiene angesetzt werden.
Bissnahmen mit Bisswall und Bissplatte sind im Zusammenhang mit einer UKPS nicht abrechenbar, da im BEL II keine entsprechenden Leistungsnummern vorhanden sind.
Die Kosten für eine Einmalbissgabel und das Bissregistriermaterial, das auf die Bissgabel aufgetragen wird, sind gesondert abrechenbar. Die Kosten für mehrfach nutzbare Bissgabeln können nicht abgerechnet werden.
