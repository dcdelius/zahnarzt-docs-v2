Erläuterungen zum Leistungsinhalt
Vestibuläre Verblendung von gegossenen Metallflächen mit Komposit durch eine in der Regel dreifarbige Standardschichtung.
Die L-Nr. 164 0 schließt die Verblendung der Schneidekante bei den Zähnen 1–3 mit ein.
Erläuterungen zur Abrechnung
Die L-Nr. 164 0 ist für die vestibuläre Verblendung einer Krone nach L-Nr. 102 4 und L-Nr. 102 8, einem Brückenglied nach L-Nr. 110 0, einer teleskopierenden Krone nach L-Nr. 120 0 und L-Nr. 120 1 oder einer Rückenschutzplatte nach L-Nr. 208 1 abrechenbar.
Die L-Nr. 164 0 ist im Rahmen der Wiederherstellung einer Verblendung auch für die Herstellung einer Facette abrechenbar.
▶ Kommentar zur BEL-L-Nr. 164 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Kann oder soll aus verschiedenen Gründen eine Verblendung nicht aus keramischen Massen hergestellt werden, stellt die Verblendung aus Komposite eine vergleichbar hochwertige, langlebige, auch kosmetisch befriedigende Art der Verblendung dar.
Ihre Oberfläche ist nahezu abriebfest, Kompositeverblendungen sind farbbeständig. Reaktionen der Materialunverträglichkeit sind nahezu unbekannt.
Eine Verblendung auch der Schneidekante ist materialbedingt bedenkenlos möglich.
An ihre Fertigung werden hohe Ansprüche gestellt: Die Metallgerüste müssen zunächst konditioniert werden; hierzu siehe L-Nr. 155 0.
Für eine Langzeitversorgung ist die Kompositeverblendung zwar nicht ohne kleine Abstriche gegenüber der Keramikverblendung vergleichbar; dass sie jedoch hierfür ungeeignet ist, kann nicht gesagt werden.
Als „Alternative“ zur Keramikverblendung gehört die Kompositeverblendung heute zum Standard von qualitätsorientierten Verblendungen.
Leistungsanwendung
Ergänzende Leistung zu den L-Nrn. 102 4, 102 8, 110 0, 120 0, 120 1, 208 1.
Über das Maß der vertragszahnärztlichen Versorgung hinausgehende (mehrflächige) „Voll-Verblendungen“ sind auch bezogen auf die hierfür benötigten anderen Metallgerüste nicht nach BEL abzurechnen.
