Erläuterungen zur Abrechnung
Die L-Nr. 020 2 ist bei der Herstellung von kieferorthopädischen Geräten mit bimaxillärer Beziehung abrechenbar.
▶ Kommentar zur BEL-L-Nr. 020 2
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Aus thermisch verformbaren Platten hergestellte Basis mit einem auch über der Zahnreihe angebrachten Bisswall aus Wachs zur Bisslagenbestimmung im Rahmen einer kieferorthopädischen Behandlung.
Basen aus thermisch verformbaren Platten sind nicht ausreichend verwindungssteif. Daraus folgt, dass bei Schienen mit adjustierter Oberfläche (L-Nrn. 401 0, ggf. 403 0) oder mit zusätzlichen Funktionsaufbissen (L-Nrn. 703 0, 710 0) zu einer präzisen Darstellung der Kiefergelenkssituation eine Basis aus thermisch verformbarem Material nicht ausreicht. Hier muss die Bissregistrierung mittels einer Basis aus Kunststoff (ggf. „Autopolymerisat“) erfolgen (L-Nr. 021 3).
Leistungsanwendung
Vorbereitende Leistung im Rahmen einer kieferorthopädischen Behandlung.
