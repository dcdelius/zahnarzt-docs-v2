▶ Kommentar zur BEL-L-Nr. 024 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Eine Übertragungskappe wird erforderlich, wenn der Gesamtabdruck den präparierten Zahn und insbesondere dessen Präparationsgrenze nur ungenügend wiedergibt. Dann wird wie folgt verfahren:
Nach einer Einzelstumpfabformung und der darauf folgenden Herstellung eines Einzelstumpfes wird darüber ein dem Stumpf enganliegendes Käppchen hergestellt, das dann zur definitiven Gesamt-Abdrucknahme über den Zahnstumpf gestülpt wird. Um das Käppchen unverrückbar im Abdruck zu fixieren, werden an seiner Außenseite kleine Retentionen angebracht. Der Einzelstumpf wird vor Ausgießen des Abdrucks in diesen reponiert.
Wegen der höheren Formstabilität ist meistens die Übertragungskappe aus Metall vorzuziehen.
Leistungsanwendung
Neben der klassischen Anwendung und Abrechnung einer Übertragungskappe ist auf Folgendes hinzuweisen:
Zunehmend wird berichtet, dass dann, wenn die Übertragungskappe aus Metall als stabilisierendes Element bei einem Langzeitprovisorium angewandt wird, Probleme bei der Abrechnung entstanden sind, obwohl die dann als „Gerüst“ dienende Übertragungskappe häufige Wiederholungen des nur aus Kunststoff bestehenden Provisoriums vermeiden hilft.
Aus Vorstehendem folgt, dass in derartigen Fällen diese Metallarmierung privat abzurechnen ist.
