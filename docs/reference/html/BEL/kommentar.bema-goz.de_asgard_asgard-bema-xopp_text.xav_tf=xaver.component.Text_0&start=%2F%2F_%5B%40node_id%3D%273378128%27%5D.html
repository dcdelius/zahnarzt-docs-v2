▶ Kommentar zur BEL-L-Nr. 850 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die „Grundeinheit für Instandsetzung oder Erweiterung einer UKPS“ deckt fertigungstechnisch den Aufwand ab, der durch Vor- und Nacharbeit bei der Durchführung der eigentlichen „Reparatur“ z. B. durch Anrauhen der Basis, „Ausarbeiten“, Polieren etc. entsteht.
Abrechnungstechnisch stellt die „Grundeinheit“ eine „Grundgebühr“ dar, die durch Hinzufügen der jeweiligen „Leistungseinheiten“ zur Gesamtleistung einer Instandsetzung oder Erweiterung wird. Eine Instandsetzung/Erweiterung setzt sich also immer aus einer Grundeinheit und Leistungseinheit(en) entsprechend der Menge der erbrachten Leistungen zusammen.
Leistungsanwendung
Die L-Nr. 850 0 ist immer nur dann abrechenbar, wenn sie in direkter Verbindung zu einer Leistung nach den „Leistungseinheiten“ der L-Nrn. 510 0, 511 0, 520 0, 521 0 und 851 1 bis 851 4 steht. Sie ist einmal je Unterkieferprotrusionsschiene abrechenbar, wenn die Reparatur in einem Kiefer erfolgt.
Wird sowohl im Ober- als auch im Unterkiefer eine Reparatur vorgenommen, ist die Grundeinheit für Instandsetzung (L-Nr. 850 0) zweimal abrechenbar.
