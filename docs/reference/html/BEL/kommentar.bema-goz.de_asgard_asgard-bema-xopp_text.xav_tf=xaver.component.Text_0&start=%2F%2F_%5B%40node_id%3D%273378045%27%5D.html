Erläuterungen zur Abrechnung
Die L-Nr. 208 3 ist bei ungünstigen Biss- und Okklusionsverhältnissen oder über einem Sekundärteil eines Kugelknopfankers abrechenbar.
Neben der L-Nr. 208 3 sind die L-Nrn. 302 0, 303 0 und 362 0 für die Metallkaufläche nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 208 3
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die Metallkaufläche kann gefertigt werden:
a) 
anstelle eines Konfektionszahnes als integrierter Bestandteil einer Metallbasis (L-Nr. 201 0), wenn der Platz zwischen Kieferkamm und Gegenzahn („Antagonisten“) so gering ist, dass ein Konfektionszahn im Prothesensattel nicht dauerhaft verankert werden kann;
b) 
als eine die gesamte Kaufläche eines natürlichen Zahnes abdeckende Auflage; diese Variante der Metallkaufläche wird angewandt, wenn mit dem Zahnersatz zugleich eine Bisslagenveränderung („Bisshebung“) vorgenommen werden soll. Bei dieser Variante der Metallkaufläche werden in der Regel zumindest alle noch verbliebenen natürlichen Seitenzähne mit Metallkaufläche occlusal bedeckt.
Die Metallkaufläche wird wie die Kaufläche einer Krone/eines Brückengliedes gestaltet.
Wird eine Metallkaufläche als Einzelleistung, also nicht in direkter Verbindung mit einem gegossenen Basisteil (L-Nr. 806 0), nachträglich an eine Metallbasis angelötet, so ist für diese Lötung die L-Nr. 807 0 abrechenbar, ferner für die eigentliche Wiederherstellungs-/Erweiterungsmaßnahme die L-Nrn. 801 0 + 802 –/861 0 + 802 –.
Leistungsanwendung
Extrem ungünstige Bissverhältnisse, Bisshebung.
