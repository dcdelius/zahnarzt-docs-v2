851 2 Leistungseinheit je Sprung/Bruch Unterkieferprotrusionsschiene
BEL-L-Nr.Leistungsinhalt
851 2
Leistungseinheit je Sprung/Bruch Unterkieferprotrusionsschiene
Kurztext laut Anlage 2
851 2LE Sprung/Bruch UKPS
Erläuterungen zum Leistungsinhalt
Sprung oder Bruch an einer Unterkieferprotrusionsschienenbasis im Kunststoff beseitigen.
Erläuterungen zur Abrechnung
Die L-Nr. 851 2 ist je zusammenhängende Sprunglinie und/oder je Bruch einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 851 2
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zusätzliche Einzelleistung bei Instandsetzung und/oder Erweiterung für eine Sprung- oder Bruchbeseitigung im Kunststoffbereich einer Unterkieferprotrusionsschiene.
Sollten an einer Unterkieferprotrusionsschiene mehrere Sprünge oder Brüche vorhanden sein, kann diese Leistung entsprechend der Anzahl abgerechnet werden.
Leistungsanwendung
Die L-Nr. 851 2 ist nur im Zusammenhang mit einer Grundeinheit nach der L-Nr. 850 0 (Grundeinheit für Instandsetzung/Erweiterung UKPS) einmal je zusammenhängende Sprunglinie oder je Bruch abrechenbar.
Wird sowohl im Ober- als auch im Unterkiefer eine Reparatur vorgenommen, ist die Grundeinheit für Instandsetzung (L-Nr. 850 0) zweimal abrechenbar.
Im Zusammenhang mit Sprung- oder Bruchreparaturen sollte eine gute Dokumentation erstellt werden.
