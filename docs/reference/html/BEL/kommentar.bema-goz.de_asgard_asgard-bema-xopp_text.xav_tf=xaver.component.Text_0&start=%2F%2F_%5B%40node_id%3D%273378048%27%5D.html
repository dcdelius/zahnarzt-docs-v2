Erläuterungen zum Leistungsinhalt
Klammer einzeln gegossen, ggf. einschließlich Duplikatmodell aus Einbettmasse.
Erläuterungen zur Abrechnung
Die L-Nr. 212 0 ist bei einer wiederherzustellenden Modellgussprothese je Prothese oder bei der Herstellung einer Kunststoffprothese mit gegossenen Halte- und/oder Stützelementen je Prothese einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 212 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Mit dem „Zuschlag für einzeln gegossene Klammer(n)“ wird der Mehraufwand abgegolten, der entsteht, wenn Klammern nicht im „Einstückguss“ mit einer neu gefertigten Metallbasis (L-Nr. 201 0) hergestellt werden. So muss z. B. bei der Einzelanfertigung einer – oder mehrerer – Klammer(n) für je einen Kiefer ein Einbettmassemodell wie für eine vollständige Metallbasis gefertigt werden.
Diese Zuschlagsposition ist also immer dann anzuwenden, wenn eine Klammer außerhalb der L-Nr. 201 0 angefertigt wird, und zwar auch dann, wenn außer der Klammer noch weitere gegossene Teile – z. B. bei einer Wiederherstellungs- und/oder Erweiterungsmaßnahme – wie Retention(en) oder gegossene(s) Basisteil(e) angefügt werden müssen.
Wird eine Klammer als Einzelleistung, also nicht in direkter Verbindung mit einem gegossenen Basisteil (L-Nr. 806 0), nachträglich an eine Metallbasis angelötet, so ist für diese Lötung die L-Nr. 807 0 abrechenbar, ferner für die eigentliche Wiederherstellungs-/Erweiterungsmaßnahme die L-Nrn. 801 0 + 802 5/861 0 + 802 5.
Leistungsanwendung
Neuanfertigung einer Kunststoffprothese mit gegossenen Klammern; Wiederherstellung oder/und Erweiterung einer Metallbasis durch Gussklammern.
Einmal je Prothese abrechenbar.
