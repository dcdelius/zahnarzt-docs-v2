—
▶ Kommentar zur BEL-L-Nr. 384 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Muss ein Konfektionszahn aus Platzgründen so weit ausgeschliffen werden, dass seine ursprüngliche Farbe dadurch verloren geht, muss er mit Kunststoff in Zahnfarbe am Prothesensattel befestigt werden.
Dieser Mehraufwand ist mit der oben beschriebenen Leistung abgedeckt.
Diese Leistung ist auch anwendbar bei Instandsetzungen/Erweiterungen.
Für den Fall eines stark atrophierten Kiefers/eines Kieferdefektes kann die Herstellung von Zahnfleisch aus Kunststoff/Composite erforderlich werden; diese Leistungen sind nach der L-Nr. 161 0 oder 165 0 zusätzlich abrechenbar (BEL = Einzelleistungsverzeichnis!).
Leistungsanwendung
Ergänzende und zusätzliche Leistung bei herausnehmbarem Zahnersatz sowie ggf. bei Schienen.
Durch die L-Nr. 384 0 wird die abrechenbare Menge der L-Nrn. 302 0, 302 8, 303 0, 362 0 und 362 8 nicht reduziert; auch die Materialkosten für den hinterlegten Zahn sind abrechenbar.
