Kurztext laut Anlage 2
202 8Umgehungsbügel bei Diastema
Erläuterungen zum Leistungsinhalt
Ergänzendes gegossenes Element, das zur Verbindung von Metallbasisteilen zur Umgehung eines Diastemas dient.
Erläuterungen zur Abrechnung
Die L-Nr. 202 8 ist auch bei festsitzendem Zahnersatz abrechenbar.
▶ Kommentar zur BEL-L-Nr. 202 8
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Der Umgehungsbügel verbindet zwei gegossene Elemente wie z. B. fortlaufende Klammern bei lückig stehenden Zähnen dadurch, dass er – meist im Oberkiefer palatinal gefertigt – dem Kiefer, z. B. die papilla incisiva umgehend, anliegt. Er wird im Modellgussverfahren hergestellt und im Frontzahngebiet angewendet.
Leistungsanwendung
Abrechenbar je Umgehungsbügel eines Diastemas.
