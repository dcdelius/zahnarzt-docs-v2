Erläuterungen zur Abrechnung
Die L-Nr. 802 4 kann für ein Basisteil Kunststoff nur abgerechnet werden, wenn an derselben Stelle keine andere Leistung erbracht wird.
Das Verkleiden der Retention ist Bestandteil der L-Nr. 802 3 „Einarbeiten Zahn“ oder L-Nr. 802 4 „Basisteil Kunststoff“ und daher als eigenständige Leistung an gleicher Stelle nicht abrechenbar.
Die L-Nr. 802 4 kann als Gegenlager einer einarmigen Klammer abgerechnet werden.
Die L-Nr. 802 4 kann bei einer Erweiterung nach L-Nr. 802 3 für die Neugestaltung eines bukkalen Schildes nicht abgerechnet werden.
Die L-Nr. 802 4 ist für das Auffüllen einer Sekundärkrone nur dann abrechenbar, wenn eine Abformung zur Basiserweiterung erfolgt ist. Sofern eine Unterfütterung notwendig ist, ist diese zusätzlich nach den L-Nrn. 808 0, 808 8, 809 0, 809 8, 810 0 und 810 8 abrechenbar.
Eine Okklusionserhöhung an getragenen Prothesen durch PMMA‐Kunststoffe kann nicht mit L‐Nr. 802 4 abgerechnet werden (vgl. L-Nr. 403 0).
▶ Kommentar zur BEL-L-Nr. 802 4
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zusätzliche Einzelleistung bei Instandsetzung und/oder Erweiterung einer Basis aus Kunststoff.
Die Ansetzbarkeit des „Basisteils aus Kunststoff“ ist gegeben, wenn die Basis an einer Stelle mit Kunststoff ergänzt werden muss, an der keine andere Leistung anfällt. Hierzu zählen z. B.:
– 
Verschluss des Gaumendachs
– 
Verlängern eines Prothesenrandes
– 
Erweiterung der Prothesenbasis im Bereich des Tubers bzw. Weisheitszahnes
– 
Anlegen eines Gegenlagers bei einer einarmigen Klammer im Rahmen einer Instandsetzung/Erweiterung
– 
Auffüllen einer Sekundärkrone nach Extraktion der Primärkrone, wenn eine Abformung zur Basiserweiterung erfolgt ist
Das Auffüllen einer Sekundärkrone mittels der Leistung „Basisteil Kunststoff“ setzt die vorausgehende Abformung voraus; das bedeutet, dass diese Leistung, wenn sie im „direkten Verfahren“ erbracht wird, nicht abrechenbar ist.
Wird im Rahmen einer Instandsetzung/Erweiterung eine einarmige Klammer angefügt, so ist in diesem Fall das erforderliche Gegenlager aus Kunststoff nach der L-Nr. 802 4 abrechenbar; diese Regelung bezieht sich nur auf Instandsetzungen oder Erweiterungen, nicht auf Neuanfertigungen!
Leistungsanwendung
Abrechenbar nur neben den Grundeinheiten nach den L-Nrn. 
– 
801 0 Grundeinheit für Instandsetzung und/oder Erweiterung einer Prothese,
– 
801 8 Grundeinheit für Instandsetzung einer implantatgestützten Prothese,
– 
861 0 Grundeinheit für Instandsetzung und/oder Erweiterung einer KFO-Basis oder
– 
eines Aufbissbehelfes,
und zwar einmal je erbrachte Einzelleistung.
Neben der L-Nr. 802 4 können weitere Leistungseinheiten nur dann abgerechnet werden, wenn diese nicht an derselben Stelle erbracht wurden.
