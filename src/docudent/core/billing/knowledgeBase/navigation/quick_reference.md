## ⚠️ VERBOTEN (Regress!)

```
❌ Cp/P ohne Material → REGRESS
❌ BEMA 12 ohne Kofferdam-Doku → REGRESS
❌ F-Code ≠ dokumentierte Flächen → PRÜFUNG
❌ WF-Anzahl ≠ WK-Anzahl → PRÜFUNG
❌ GOZ 2197 neben GOZ 2060-2120 → DOPPELT
❌ Gleichartig: Abformung als GOZ (in BEMA 20a!)
```

## 🔄 Gleichartig vs. Andersartig

| Aspekt | Gleichartig | Andersartig |
|--------|-------------|-------------|
| Beispiel | Vollkeramik statt Metall | Implantat statt Brücke |
| BEMA | Ja (Kassenanteil) | NEIN |
| GOZ | Nur Mehrleistungen | Komplett |
| Labor | BEL + Differenz | Komplett privat |

## 📋 Checkliste neue Behandlung

### PKV
- [ ] GOZ 0080 VOR Injektion?
- [ ] Richtige Anästhesie?
- [ ] Kofferdam (GOZ 2040)?
- [ ] Bei Endo: GOZ 2400 (Längenmessung)?
- [ ] Material separat?
- [ ] Steigerung möglich?

### GKV
- [ ] Kofferdam dokumentiert?
- [ ] Cp/P mit Material?
- [ ] F-Code = Flächen?
- [ ] Bei MKV: Schriftlich VOR Behandlung?
