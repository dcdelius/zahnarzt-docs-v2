## 1. Typischer Behandlungsablauf (Zahnmedizinisch korrekt)

### Chronologische Reihenfolge:

1. **Aufklärung & Einwilligung**
   - Kosten, Alternativen, Risiken (postoperative Sensibilität)

2. **Anästhesie** (ggf.)
   - Infiltration (OK, UK-Front) oder Leitung (UK-Seitenzahn)
   - BEMA 40 / BEMA 41a

3. **Trockenlegung**
   - Kofferdam (BEMA 12 / GOZ 2040) = Gold-Standard
   - Relative Trockenlegung (Watterollen) = keine separate Abrechnung

4. **Exkavation**
   - Entfernung kariöser Substanz bis sondenhart
   - Keine separate BEMA-Position (Teil der Füllung)

5. **Überkappung** (bei tiefer Karies)
   - Cp (indirekt) = BEMA 25 / GOZ 2330
   - P (direkt) = BEMA 26 / GOZ 2340

6. **Konditionierung/Adhäsiv**
   - Säure-Ätzung, Dentinadhäsiv
   - **GKV:** Im BEMA 13 enthalten (selbstadhäsive Materialien)
   - **PKV:** In GOZ 2060-2100 enthalten
   - **Zuzahlung GKV:** GOZ 2197 (umstritten!)

7. **Matrizentechnik** (bei Approximalflächen)
   - Teilmatrize, Keil, Ring
   - In BEMA/GOZ Füllungsposition enthalten

8. **Füllung einbringen**
   - **GKV Standard:** Bulk-Fill oder selbstadhäsiv einschichtig
   - **PKV/Zuzahlung:** Mehrschichttechnik (schichtweise)

9. **Okklusionskontrolle**
   - Artikulationspapier, ggf. Einschleifen
   - In BEMA/GOZ Füllungsposition enthalten

10. **Politur**
    - Brownie/Greenie oder Polierscheiben
    - In BEMA/GOZ Füllungsposition enthalten

11. **Fluoridierung** (optional)
    - BEMA IP4 / GOZ 1020

12. **Entlassung**
    - Hinweis auf mögliche Sensibilität

## 4. GOZ 2197: Adhäsive Befestigung (Kontroverse)

### Was ist GOZ 2197?

**Leistungsinhalt:** Physikalisch-chemische Konditionierung von Zahnflächen 
(Schmelz, Dentin, Wurzeldentin) + Anwendung eines Adhäsivsystems.

**Kosten:** 130 Punkte × 5,62421 ct = **16,82€** (bei Faktor 2,3)

### Warum ist GOZ 2197 umstritten?

**Position der Bundeszahnärztekammer (BZÄK):**
> Die adhäsive Befestigung ist bereits Bestandteil der GOZ-Füllungspositionen 
> (GOZ 2060-2120) und darf daher NICHT zusätzlich berechnet werden.

**Gegenposition (einige Gerichte):**
> GOZ 2197 ist separat berechnungsfähig, da es sich um eine eigenständige 
> Leistung handelt, die über die Füllungsposition hinausgeht.

**Praktisches Problem:**
- Private Kostenträger (Beihilfe, Zusatzversicherungen) lehnen GOZ 2197 
  neben Kompositfüllungen häufig ab
- Erstattungsprobleme für Patienten

### Regel für unseren Output

```
GOZ 2197 VERWENDEN bei:
  ✓ GKV-Patient mit Zuzahlung (Mehrkostenvereinbarung)
    → GOZ 2197 auf Privatrechnung zusätzlich zu BEMA 13
  ✓ Adhäsive Befestigung von Inlays, Veneers, Kronen
    → Hier ist GOZ 2197 unstrittig

GOZ 2197 NICHT VERWENDEN bei:
  ✗ PKV-Patient mit Kompositfüllung
    → Bereits in GOZ 2060-2120 enthalten (BZÄK-Meinung)
  ✗ GKV-Patient ohne Mehrkostenvereinbarung
    → In BEMA 13 keine Adhäsivtechnik enthalten/abrechenbar
```

- Funktional ausreichend, aber weniger dauerhaft

## 5. Kritische Erkenntnis: Text = Billing

### Was im Text steht MUSS abgerechnet werden:

| Text | GKV | PKV |
|------|-----|-----|

### REGEL:

```
IF (Text enthält "Mehrschicht" OR "schichtweise" OR "Adhäsiv"):
    IF (Versicherung == GKV):
        → Entweder Zuzahlung dokumentieren
        → ODER Text anpassen (kein "schichtweise")
    ELSE (PKV):
        → Bereits in GOZ enthalten
```

## 10. Strategien für unseren Output


### Strategie 1: Versicherungsabhängige Texte

Der Text muss zur Abrechnung passen:

| Versicherung | Text für Komposit |
|--------------|-------------------|
| GKV (ohne Zuzahlung) | "Komposit eingebracht, lichthärtend" |
| GKV (mit Zuzahlung) | "Komposit in Mehrschichttechnik" |
| PKV | "Komposit in Mehrschichttechnik schichtweise appliziert" |

### Strategie 2: Zuzahlung-Flag

Wenn GKV-Patient und Diktat enthält "Mehrschicht/schichtweise":
→ Flag setzen: `hasZuzahlung: true`
→ Text darf "Mehrschicht" enthalten
→ Billing zeigt BEMA + GOZ separat

### Strategie 3: Konsistenzprüfung

Nach Generierung: Prüfe ob jeder Text-Block einen Billing-Code hat:
- "Leitungsanästhesie" → BEMA 41a muss vorhanden sein
- "Kofferdam" → BEMA 12 muss vorhanden sein
- "Überkappung" → BEMA 25/26 muss vorhanden sein
- "Mehrschicht" → Zuzahlung muss dokumentiert sein (bei GKV)

## 11. Zusammenfassung für Implementierung

1. **Ein Chip pro Leistung**, aber mit versicherungsabhängigem Text
2. **Jeder Text-Block verlinkt zu billingRef**
3. **Zuzahlung bei GKV** = separate GOZ-Positionen auf Privatrechnung
4. **PKV** = alles in GOZ, Mehrschicht inklusive
5. **Konsistenzprüfung** nach Generierung
