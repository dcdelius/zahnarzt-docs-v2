Befestigungselement Protrusionselement für Unterkieferprotrusionsschiene
Kurztext laut Anlage 2
510 0Befestigungselement Protrusionselement UKPS
Erläuterungen zum Leistungsinhalt
Einarbeiten eines individuellen oder konfektionierten Elements in eine Basis der Unterkieferprotrusionsschiene zur Aufnahme eines Protrusionselements.
Erläuterungen zur Abrechnung
Die L-Nr. 510 0 ist je Unterkieferprotrusionsschiene bis zu viermal abrechenbar.
Die L-Nr. 510 0 ist auch für die Erneuerung eines Befestigungselements abrechenbar.
▶ Kommentar zur BEL-L-Nr. 510 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 510 0 beschreibt das Einarbeiten eines individuellen oder konfektionierte Elements in eine Basis der UKPS zur Aufnahme eines Protrusionselements. Die Leistung kann auch für die Erneuerung bzw. Instandsetzung eines Befestigungselements angesetzt werden.
Leistungsanwendung
Die L-Nr. 510 0 kann sowohl für konfektionierte als auch individuelle Protrusionselemente abgerechnet werden. Beim Einsatz von konfektionierten Protrusionselementen kann der Materialaufwand zusätzlich in Rechnung gestellt werden.
Bei der Neuanfertigung einer UKPS müssen die L‐Nrn. 510 0 und 511 0 aus Plausibilitätsgründen zusammen abgerechnet werden. Bei Wiederherstellungen erfolgt die Abrechnung entsprechend der jeweiligen Wiederherstellungsmaßnahme.
Das Einarbeiten eines individuellen oder konfektionierten Elements kann bis zu viermal sowohl für Neuanfertigungen als auch Instandsetzungen abgerechnet werden.
Die Materialkosten für „Protrusionssystem‐Sets und konfektionierte Protrusionselemente“ sind gesondert abrechenbar.
