Montage Protrusionselement für Unterkieferprotrusionsschiene
Kurztext laut Anlage 2
511 0Montage Protrusionselement UKPS
Erläuterungen zum Leistungsinhalt
Montage und Justierung eines konfektionierten Protrusionselements an bis zu zwei Befestigungselementen nach L-Nr. 510 0. Das Protrusionselement nach der L-Nr. 511 0 muss eine Justierung der Protrusion mindestens in Millimeterschritten ermöglichen.
Erläuterungen zur Abrechnung
Die L-Nr. 511 0 ist je Unterkieferprotrusionsschiene bis zu zweimal abrechenbar.
Die L-Nr. 511 0 ist auch für die Erneuerung eines Protrusionselements abrechenbar.
▶ Kommentar zur BEL-L-Nr. 511 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Unter der L-Nr. 511 0 wird die Montage und Justierung eines konfektionierten Protrusionselements an bis zu zwei Befestigungselementen nach L-Nr. 510 0 abgerechnet. Das Protrusionselement muss eine Justierung der Protrusion mindestens in Millimeterschritten ermöglichen.
Leistungsanwendung
Die L-Nr. 511 0 kann sowohl für Neuanfertigungen als auch für Instandsetzungen abgerechnet werden und ist je UPKS maximal zweimal abrechenbar.
Bei der Neuanfertigung einer UKPS müssen die L‐Nrn. 510 0 und 511 0 aus Plausibilitätsgründen zusammen abgerechnet werden.
Beim Austausch eines unbrauchbar gewordenen Protrusionselements wird die Grundeinheit für Instandsetzung (L-Nr. 850 0) zusätzlich abgerechnet.
Die Materialkosten für „konfektionierte Protrusionselemente“ (z. B Protrusionsset) sind gesondert abrechenbar.
