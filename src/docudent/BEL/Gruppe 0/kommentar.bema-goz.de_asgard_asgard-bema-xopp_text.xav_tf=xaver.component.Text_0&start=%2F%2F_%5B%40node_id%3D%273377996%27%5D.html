Registrierplatte und -stift auf Basen für Stützstiftregistrierung
Kurztext laut Anlage 2
023 0Registrierplatte und -stift auf Basen
Erläuterungen zum Leistungsinhalt
Anbringen des aus Registrierplatte und Registrierstift bestehenden Registrierbestecks auf Oberkiefer- und Unterkieferbasis aus Kunststoff zur Vorbereitung einer Stützstiftregistrierung.
Erläuterungen zur Abrechnung
Die L-Nr. 023 0 ist für das Anbringen des Registrierbestecks einmal je vorbereitete Stützstiftregistrierung neben den Basen nach L-Nr. 021 4 abrechenbar.
Neben der L-Nr. 023 0 ist die L-Nr. 022 0 nur einmal je vorbereitete Stützstiftregistrierung abrechenbar.
▶ Kommentar zur BEL-L-Nr. 023 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 023 0 „Registrierplatte und -stift auf Basen für Stützstiftregistrierung“ ergänzt die hierfür vorgesehenen Basen für Stützstiftregistrierung (L-Nr. 021 4) zu einem der „einfachen“ Bissregistrierung überlegenen Hilfsmittel zur Optimierung der Bisslagenbestimmung.
Die L-Nr. 023 0 ist eine auf beide Kiefer bezogene Gesamtleistung.
Um eine abstandsgerechte Anbringung des Registrierbestecks zu erreichen, kann es erforderlich sein, dass auf den Basen Bisswälle angebracht werden müssen; siehe hierzu L-Nr. 022 0.
Leistungsanwendung
Die L-Nr. 023 0 ist einmal je komplettes Registrierbesteck, also bezogen auf Ober- und Unterkiefer, abrechenbar.
Die Materialkosten des Registrierbestecks sind gesondert abrechenbar.
