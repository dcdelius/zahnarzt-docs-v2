Erläuterungen zum Leistungsinhalt
Vorhandenen Zahnkranz bearbeiten und zum Sägemodell, Einzelstumpfmodell oder Set-up-Modell zur Herstellung eines Positioners vervollständigen.
Erläuterungen zur Abrechnung
Die L-Nr. 007 0 ist vom Praxislabor abrechenbar, wenn die L-Nr. 006 0 durch das gewerbliche Labor erbracht und abgerechnet wird.
▶ Kommentar zur BEL-L-Nr. 007 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Zweiter Teil der Herstellung eines Modells zur Stumpfherstellung.
Der bereits fertige, ggf. mit Führungsstiften (Dowel-pins) versehene Zahnkranz wird mit einem Sockel aus Gips versehen.
Leistungsanwendung
In der Regel ist diese Leistung nur vom gewerblichen Labor abrechenbar. Einzige – eher seltene – Ausnahme: Der Zahnkranz wurde vom gewerblichen Labor in der Zahnarztpraxis hergestellt (siehe hierzu Kommentar zur L-Nr. 006 0!).
