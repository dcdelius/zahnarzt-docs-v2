Erläuterungen zum Leistungsinhalt
Herstellung eines Zahnkranzes im Praxislabor zur späteren Ergänzung mit einem Gipssockel zu einem Sägemodell oder einem Einzelstumpfmodell oder einem Set-up-Modell für die KFO-Planung oder Herstellung eines Positioners durch das gewerbliche Labor.
Erläuterungen zur Abrechnung
Die L-Nr. 006 0 ist nicht durch das gewerbliche Labor abrechenbar, es sei denn, der Leistungsinhalt wird durch das gewerbliche Labor in der Zahnarztpraxis erbracht.
▶ Kommentar zur BEL-L-Nr. 006 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Erster Teil eines Modells zur Stumpfherstellung. In der Praxis des Zahnarztes wird der Abdruck nur so weit mit Gips ausgegossen, dass etwas mehr als die Zahnabformungen ausgefüllt sind.
Durch vorheriges Setzen oder nachträgliches Bohren und Einkleben von Führungsstiften (Dowel-Pins) in den ausgegossenen Zahnkranz werden diejenigen Teile des Zahnkranzes vorbereitet, die aus dem Modellsockel (L-Nr. 007 0) herausnehmbar sein sollen.
Leistungsanwendung
Die L-Nr. 006 0 löst nachfolgend die L-Nr. 007 0 (Zahnkranz sockeln) aus. Beide, abrechnungstechnisch ausschließlich auf den Fertigungsort bezogene Leistungen entsprechen einem „Modell zur Stumpfherstellung“. Die alleinige Beziehung auf den Fertigungsort ermöglicht nun auch die Abrechnung durch das gewerbliche Labor, wenn dessen Mitarbeiter in der Zahnarztpraxis tätig geworden ist.
