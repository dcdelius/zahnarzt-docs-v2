Erläuterungen zum Leistungsinhalt
Aufstellung eines Konfektionszahnes auf Wachsbasis oder Kunststoffbasis.
Erläuterungen zur Abrechnung
Die L-Nr. 302 0 ist entsprechend der Zahl der aufgestellten konfektionierten Zähne abrechenbar.
Die L-Nr. 302 0 ist erneut abrechenbar, wenn eine weitere Bissnahme erforderlich ist.
▶ Kommentar zur BEL-L-Nr. 302 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 302 0 deckt den Aufwand ab, der mit dem Aufstellen eines Zahnes auf eine Wachsbasis oder Kunststoffbasis z. B. durch Beschleifen etc. verbunden ist.
Aufstellungen, die für eine Anprobe im Mund des Patienten bestimmt sind, sollten grundsätzlich auf einer Kunststoffbasis erfolgen, da eine Wachsbasis nicht ausreichend verwindungssteif ist.
Wird im Anschluss an die Aufstellung auf Wachs- oder Kunststoffbasis eine Metallbasis gefertigt, so ist für die Übertragung der bereits aufgestellen Zähne die L-Nr. 341 0 anzuwenden (1 × je übertragenen Zahn).
Da die exakte und eindeutige Bissregistrierung sehr schwierig und von vielen Faktoren abhängig ist, ist für den Fall, dass wegen „Insuffizienz des stomatognaten Systems“ ein neuer Biss genommen und demzufolge neu einartikuliert werden muss (L-Nr. 012 0 ein weiteres Mal anzusetzen), die L-Nr. 302 0 erneut je umgestellten Zahn anzusetzen.
Die L-Nr. 302 0 ist auch anwendbar bei aus Kunststoff hergestellten Schienen („Aufbissbehelfen“) sowie ggf. neben der L-Nr. 701 0.
 
Leistungsanwendung
Ergänzende Leistung zur L-Nr. 301 0; sie wird unter Berücksichtigung ihrer jeweiligen Menge zur „Gesamtleistung Aufstellung“.
