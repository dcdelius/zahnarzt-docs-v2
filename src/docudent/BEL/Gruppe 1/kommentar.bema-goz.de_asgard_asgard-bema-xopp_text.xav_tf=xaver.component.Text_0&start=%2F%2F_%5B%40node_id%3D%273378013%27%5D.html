Erläuterungen zur Abrechnung
Die L-Nr. 110 0 ist je tatsächlich gefertigter Zahneinheit abrechenbar.
Für die vestibuläre Verblendung eines Brückengliedes nach L-Nr. 110 0 sind die L-Nrn. 160 0, 162 0 oder 164 0 abrechenbar.
▶ Kommentar zur BEL-L-Nr. 110 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 110 0 schließt alle aus einer Dentallegierung gegossenen Brückenglieder, auch für Verblendung, ein.
Das Brückenglied kann mit einem gefrästen Lager nach der L-Nr. 136 0 versehen werden.
Der Hinweis in der Erläuterung zum Leistungsinhalt stellt klar, dass das Brückenglied „unter Verwendung eines Mittelwertartikulators“ zu fertigen ist. Daraus folgt zwingend, dass die Kauflächengestaltung nur nach mittleren Kiefergelenkswerten, nicht jedoch nach der individuellen Kiefergelenksrelation des einzelnen Patienten zu gestalten ist.
Das Einstellen in einen Fixator (L-Nr. 011 2) reicht für die Herstellung eines Brückengliedes nicht aus.
Leistungsanwendung
Ein Brückenglied nach der L-Nr. 110 0 ist sowohl bei festsitzendem als auch herausnehmbarem Zahnersatz, z. B. zwischen zwei teleskopierenden Kronen, abrechenbar.
