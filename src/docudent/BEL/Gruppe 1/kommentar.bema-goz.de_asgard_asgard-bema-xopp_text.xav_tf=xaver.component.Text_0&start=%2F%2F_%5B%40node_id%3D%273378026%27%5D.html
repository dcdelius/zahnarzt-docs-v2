Zahnfleisch aus Kunststoff
Kurztext laut Anlage 2
161 0Zahnfleisch Kunststoff
Erläuterungen zum Leistungsinhalt
Herstellen von Zahnfleischpartien aus Kunststoff zum Ausgleich von Alveolaratrophien, Kieferdefekten und Stellungsanomalien.
Erläuterungen zur Abrechnung
Die L-Nr. 161 0 ist einmal je Zahn abrechenbar.
▶ Kommentar zur BEL-L-Nr. 161 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die qualitativen Bedenken hinsichtlich der Abriebfestigkeit von PMMA-Kunststoffen, wie sie bereits bei der Kommentierung zur L-Nr. 160 0 aufgeführt sind, gelten auch bei dieser, sich auf eine Verblendung nach der L-Nr. 160 0 beziehenden Leistung.
Aus zahntechnisch-fachlicher Sicht ist auch das Zahnfleisch aus Kunststoff zumindest bei festsitzendem Zahnersatz kontraindiziert.
Leistungsanwendung
Ergänzung einer Verblendung aus Kunststoff – allenfalls anwendbar bei herausnehmbarem Zahnersatz.
