Gegossene Wurzelstiftkappe aus Metall im indirekten Verfahren.

Erläuterungen zur Abrechnung
Die L-Nr. 101 3 ist als Träger eines Kugelknopfankers abrechenbar. Das Anbringen des Kugelknopfankers wird nach der L-Nr. 134 3 abgerechnet.
Die L-Nr. 101 3 ist neben der L-Nr. 105 0 nicht abrechenbar.
▶ Kommentar zur BEL-L-Nr. 101 3
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die gegossene Wurzelstiftkappe nach der L-Nr. 101 3 wird für einen Zahnstumpf gefertigt, bei dem die natürliche Zahnkrone sowie die Pulpa entfernt wurde. Die frühere, weitergehende Indikation, wonach auf die Wurzelstiftkappe ein Aufbau als Träger einer Krone gefertigt wurde, ist im Rahmen der vertragszahnärztlichen Versorgung aufgegeben worden. Sie ist in diesem Bereich nur noch auf die Kombination mit einem konfektionierten Kugelknopfanker beschränkt.
Auch die frühere Praxis, auf eine Wurzelstiftkappe das eine Ende einer Stegverbindung aufzulöten, ist durch den Wegfall der Position „Steg“ im BEL ausgeschlossen.
Leistungsanwendung
Der Hinweis in den Erläuterungen zur Abrechnung „Die L-Nr. 101 3 ist neben der L-Nr. 105 0 nicht abrechenbar“ ist insoweit irreführend, als an einem anderen Zahn im gleichen oder gegenüberliegenden Kiefer durchaus eine Leistung nach der L-Nr. 105 0 abrechenbar ist. Der Hinweis bezieht sich also nur auf den gleichen Zahn.
