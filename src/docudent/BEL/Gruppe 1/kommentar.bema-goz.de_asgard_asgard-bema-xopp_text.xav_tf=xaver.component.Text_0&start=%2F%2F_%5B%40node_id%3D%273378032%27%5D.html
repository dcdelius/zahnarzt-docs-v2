Zahnfleisch aus Komposit
Kurztext laut Anlage 2
165 0Zahnfleisch Komposit
Erläuterungen zum Leistungsinhalt
Herstellen von Zahnfleischpartien aus Komposit zum Ausgleich von Alveolaratrophien, Kieferdefekten und Stellungsanomalien.
Erläuterungen zur Abrechnung
Die L-Nr. 165 0 ist einmal je Zahn, auch für Wurzelpontic, abrechenbar.
▶ Kommentar zur BEL-L-Nr. 165 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Um z. B. bei einem Brückenglied einen gleichmäßigen Verlauf des Zahnfleischsaumes zu den Nachbarzähnen zu erzielen, ist es bei Vorliegen von Kieferdefekten jeglicher Art notwendig, die fehlende Kiefersubstanz durch künstliches Zahnfleisch auszugleichen.
Diese Leistung wird mit der L-Nr. 165 0 beschrieben.
Leistungsanwendung
Die L-Nr. 165 0 ist auch abrechenbar für ein Wurzelpontic.
