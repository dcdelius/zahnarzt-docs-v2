Erläuterungen zum Leistungsinhalt
Vestibuläre Verblendung von gegossenen Metallflächen mit Kunststoff durch eine in der Regel dreifarbige Standardschichtung.
Erläuterungen zur Abrechnung
Die L-Nr. 160 0 ist für die vestibuläre Verblendung einer Krone nach L-Nr. 102 4 und L-Nr. 102 8, einem Brückenglied nach L-Nr. 110 0, einer teleskopierenden Krone nach L-Nr. 120 0 und L-Nr. 120 1 oder einer Rückenschutzplatte nach L-Nr. 208 1 abrechenbar.
Die L-Nr. 160 0 ist im Rahmen der Wiederherstellung einer Verblendung auch für die Herstellung einer Facette abrechenbar.
▶ Kommentar zur BEL-L-Nr. 160 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die unter der L-Nr. 160 0 beschriebene „Vestibuläre Verblendung Kunststoff“ ist die einfachste Verblendung; sie besteht aus Polymethylmetacrylat (PMMA) sowie einer in der Regel dreifarbigen Standardschichtung (Dentin – Zahnhals – Schneide) entsprechend dem Farbmuster eines konfektionierten „Farbringes“. Dieses Material PMMA bedarf wegen seiner geringen Abriebfestigkeit unbedingt einer metallenen Schneidekante.
Materialbedingt sollten Verblendungen nach der L-Nr. 160 0 nicht mehr in Frage kommen, zumindest nicht bei fest inkorporiertem Zahnersatz.
In vielen Fällen können PMMA-Kunststoffe der Mundflora nicht widerstehen, so dass es zu Verfärbungen kommt.
Die Befestigung einer Verblendung auf dem Metallgerüst erfolgt mittels auf das Metallgerüst aufgebrachter Retentionen („mechanische Verbindung“). Fehlen – z. B. bei einer Erneuerung der Verblendung – die Retentionen, so müssen neue Retentionen auf die Oberfläche des Metallgerüstes aufgebracht werden.
Um also bei Fehlen ausreichender Retentionen auf dem vorhandenen Metallgerüst (z. B. Sekundärteil einer teleskopierenden Krone) eine fachgerechte und haltbare Erneuerung der Verblendung vornehmen zu können, bedarf es des Anlötens neuer Retentionen.
Leistungsanwendung
Die L-Nr. 160 0 kann nur noch sehr beschränkt und nur dann eine ergänzende Leistung zu den L-Nrn. 102 4, 110 0, 120 0, 120 1 und 208 1 sein, wenn es sich um eine Leistung im Seitenzahngebiet handelt.
Für das Anbringen neuer Retentionen zur Befestigung von PMMA-Verblendungen sind die Leistungen

802 7

803 0 
Retention, gebogen (ggf. 804 0 Retention, gegossen);
820 0 
Reparatur einer Krone oder eines Brückengliedes
zusätzlich abrechenbar.
