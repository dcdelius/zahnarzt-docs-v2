▶ Kommentar zur BEL-L-Nr. 704 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die Vorhofplatte wird aus Kunststoff individuell gefertigt.
Sie ist im Mundvorhof angesiedelt und dient als kieferorthopädisches Gerät dem Zweck, Stellungsanomalien verursachenden Druck von Lippen, Wangen oder Zunge abzuleiten.
Sind zusätzliche Aufbisse und Abschirmelemente erforderlich, so sind diese zusätzlich ansetzbar.
