Basis für bimaxilläres Gerät
Kurztext laut Anlage 2
702 0Basis bimaxilläres Gerät
Erläuterungen zum Leistungsinhalt
Basis für bimaxilläres Gerät aus Kunststoff für verschiedene Arten kieferorthopädischer Apparaturen, auch elastisch, einschließlich Radieren nach System und Abdecken von Kieferteilen.
Erläuterungen zur Abrechnung
Bei horizontaler Teilung ist statt der L-Nr. 702 0 zweimal die L-Nr. 701 0 abrechenbar.
Die L-Nr. 702 0 ist auch für einen individuell gefertigten Positioner abrechenbar.
▶ Kommentar zur BEL-L-Nr. 702 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Voraussetzung für die Herstellung einer beide Kiefer einbeziehenden Basis für bimaxilläres Gerät ist die Bisslagenbestimmung mittels Konstruktionsbiss (L-Nr. 020 2) sowie das Einstellen des Modellpaares in Fixator (L-Nr. 011 2).
Die „Basis für bimaxilläres Gerät“, aus hartem Kunststoff hergestellt, dient als „funktionskieferorthopädisches Gerät“, mit dessen Hilfe durch „Einschleifen“ etc. Zahnstellungsanomalien behoben werden sollen. Die L-Nr. 702 0 ist auch ansetzbar für einen aus Weichkunststoff hergestellten Positioner, der als individuell gefertigtes Nachbehandlungsgerät eingesetzt wird; hierbei fällt zusätzlich die L-Nr. 712 1 „Verarbeitung von Weichkunststoff“ an.
Bei der Herstellung eines Positioners können weitere Leistungen anfallen; diese sind unter den L-Nrn.
003 0 
Set-up je Segment;
002 1 
Doublieren;
005 4 
Set-up-Modell;
012 0 
Einstellen in Mittelwertartikulator
ansetzbar.
Die „Basis für bimaxilläres Gerät“ wird sowohl funktional (z. B. nach entsprechendem Einschleifen) als auch als Träger kieferorthopädischer Funktionselemente wie Labialbögen etc. eingesetzt.
Werden zwischen einem geteilten bimaxillären Gerät Verbindungs- oder Führungselemente eingearbeitet, so ist diese Leistung nach der L-Nr. 741 0 (je Paar) ansetzbar.
Leistungsanwendung
Einsetzbar sowohl als funktionskieferorthopädisches („FKO“) oder Nachbehandlungsgerät („Positioner“).
