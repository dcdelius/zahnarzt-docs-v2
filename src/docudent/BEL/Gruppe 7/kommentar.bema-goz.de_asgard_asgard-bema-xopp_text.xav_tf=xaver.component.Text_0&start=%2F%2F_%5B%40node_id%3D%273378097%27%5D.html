Erläuterungen zum Leistungsinhalt
Die L-Nr. 740 0 beinhaltet ein intramaxilläres Verbindungselement wie z. B. Coffin-Feder, Transversalbügel, orthodontischer Lingual- oder Palatinalbogen, Verbindung zwischen Basisteilen.
Erläuterungen zur Abrechnung
—
▶ Kommentar zur BEL-L-Nr. 740 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Das „Verbindungselement intramaxillär“ wird aus stabilem federharten Draht gebogen und erfüllt verschiedene Aufgaben:
1. 
Die Coffin-Feder verbindet die beiden Teile eines kieferorthopädischen Gerätes miteinander, indem sie an ihren beiden Enden im Kunststoff verankert ist.
2. 
Transversalbügel werden entweder direkt an konfektionierte oder individuell gefertigte Bänder angelötet (Fixierung) oder unter Zuhilfenahme von Röhrchen etc. zum Zwecke der Aktivierbarkeit abnehmbar gefertigt.
3. 
Der „orthodontische Lingual- oder Palatinalbogen“ kann ähnliche Funktionen wie der Transversalbügel, z. B. bei der Fertigung eines „Quad-Helix“-Gerätes, erfüllen.
Der Transversalbügel, Lingual- oder Palatinalbogen stehen in direkter Beziehung zu anderen, weiteren orthodontischen Einzelelementen. In deren Folge kommt es meist zu Lötungen; diese Leistung ist nach der L-Nr.
744 0

ansetzbar.
