Grundeinheit für Instandsetzung und/oder Erweiterung einer Prothese
Kurztext laut Anlage 2
801 0Grundeinheit ZE
Erläuterungen zum Leistungsinhalt
Instandsetzung und/oder Erweiterung einer Prothese im Kunststoff- oder Metallbereich.
Erläuterungen zur Abrechnung
Die L-Nr. 801 0 ist als Grundeinheit einmal je Prothese in Verbindung mit den L-Nrn. 802 1-7, 160 0, 164 0 sowie 383 0 und 384 0 abrechenbar.
▶ Kommentar zur BEL-L-Nr. 801 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die „Grundeinheit für Instandsetzung und/oder Erweiterung einer Prothese“ deckt fertigungstechnisch den Aufwand ab, der durch Vor- und Nacharbeit bei der Durchführung der eigentlichen „Reparatur“ z. B. durch Anrauhen der Basis, „Ausarbeiten“, Polieren etc. entsteht.
Abrechnungstechnisch stellt die „Grundeinheit“ eine „Grundgebühr“ dar, die durch Hinzufügen der jeweiligen „Leistungseinheiten“ zur Gesamtleistung einer Instandsetzung und/oder Erweiterung wird. Eine Instandsetzung/Erweiterung setzt sich also immer aus einer Grundeinheit und Leistungseinheit(en) in der Menge der erbrachten Leistungen zusammen.
Fallen im Rahmen der Leistung nach L-Nr. 801 0 Metallverbindungen an, so sind diese Leistungen – unter Beachtung des Kommentars zu den L-Nrn. 803 0, 804 0, 806 0 und 807 0 – unter der L-Nr.
807 0 
Metallverbindung bei Wiederherstellung/Erweiterung
anzusetzen.
Bei der Erneuerung einer Verblendung an einem herausnehmbaren Zahnersatz ist die jeweilige Verblendung (L-Nr. 160 0/164 0) wie eine Leistungseinheit anzusehen und abzurechnen.
Die L-Nrn. 383 0 und 384 0 sind auch im „Reparatur“-Bereich unter Beachtung von deren – für diesen Bereich zwar nicht ausdrücklich genannten, dem Sinne nach aber wohl analog anzuwendenden – Erläuterungen ansetzbar. Demzufolge ersetzt beim Herstellen eines Zahnes die L-Nr. 383 0 die L-Nr. 802 3, während beim Hinterlegen eines Konfektionszahnes neben der L-Nr. 384 0 sowohl die L-Nr. 802 3 als auch der verwendete Konfektionszahn ansetzbar ist.
Leistungsanwendung
Grundleistungseinheit für herausnehmbaren Zahnersatz.
Die L-Nr. 801 0 ist immer dann abrechenbar, wenn sie in direkter Verbindung zu einer Leistung nach den „Leistungseinheiten“ der Nrn. 802 1 bis 802 7 bzw. zu einer Verblendung sowie den L-Nrn. 383 0 und 384 0 bei herausnehmbarem und wiederherzustellendem Zahnersatz steht.
