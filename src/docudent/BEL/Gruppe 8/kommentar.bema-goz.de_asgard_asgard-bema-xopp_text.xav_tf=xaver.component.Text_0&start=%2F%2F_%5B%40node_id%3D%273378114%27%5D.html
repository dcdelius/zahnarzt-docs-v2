Die L-Nr. 803 0 ist je Retention einmal abrechenbar.
▶ Kommentar zur BEL-L-Nr. 803 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die L-Nr. 803 0 beinhaltet alle Leistungen, die zur Herstellung (Biegen des Drahtes), dem Einarbeiten (Überschleifen des Konfektionszahnes über die Retention bzw. Anpassen der Retention an den Konfektionszahn) sowie ggf. dem Anlöten der „Einzelretention“ an die Metallbasis erforderlich sind.
Als „Einzelretention“ gilt in der Regel die für einen Zahn gefertigte Retention auch dann, wenn für mehrere nebeneinanderstehende Zähne je eine Retention gefertigt wird.
Ist an einem in einem Abdruck einzubringenden Platzhalter (L-Nr. 002 2) keine ausreichende Retention vorhanden, kann eine weitere, unter der L-Nr. 803 0 anzusetzende Retention angebracht werden.
Leistungsanwendung
Die gebogene Retention fällt in der Regel bei Instandsetzung/Erweiterung einer Metallbasis an, wenn dort Zähne angefügt werden müssen. Sie dient ggf. auch als Stabilisierungselement bei einem oder mehreren einzeln stehenden Zähnen an einer Kunststoffbasis, z. B. bei tiefem Biss.
Abrechenbar je gefertigte, aus Draht gebogene Einzelretention.
