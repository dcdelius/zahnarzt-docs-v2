Kurztext laut Anlage 2
862 0LE Einfügen Regulierungs- oder Halteelement
Erläuterungen zum Leistungsinhalt
Einfügen eines neuen Elementes, z. B. Dehn-, Halte-, Regulierungs-, Abstütz- oder Abschirmelementes oder eines Aufbisses, ggf. einschließlich des Herauslösens des defekten Elementes.
Erläuterungen zur Abrechnung
Die L-Nr. 862 0 ist je eingefügtem Element einmal abrechenbar; dies gilt auch für Halte- und Stützelemente, die nach den L-Nrn. 388 0 und 381 0 abrechenbar sind.
▶ Kommentar zur BEL-L-Nr. 862 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die „Leistungseinheit Einfügen Regulierungs-/Halteelement“ für das Herauslösen eines defekten Elementes und Einfügen eines neuen Elementes ergänzt die „Grundeinheit für Instandsetzung und/oder Erweiterung einer KFO-Basis oder eines Aufbissbehelfes“. Sie ist somit keine eigenständige Leistung, sondern nur in Verbindung mit der L-Nr. 861 0 (Grundeinheit/Instands. KFO oder Aufbissbehelf) berechenbar.
Das Einarbeiten von konfektionierten Dehn- oder Regulierungseinheiten macht das erneute Trennen der Basis erforderlich; diese Leistung ist unter der L-Nr. 722 0 anzusetzen.
Fallen im Zuge der Instandsetzung und/oder Erweiterung eines kieferorthopädischen Gerätes/Aufbissbehelfes weitere Leistungseinheiten an, so sind diese ebenfalls nach der L-Nr. 862 0 anzusetzen.
Die Herstellung einer Klammer, Feder, eines Bogens, einer Retention, eines Aufbisses etc. ist eine unter der jeweiligen BEL-Position zusätzlich zu dieser Leistungseinheit anzusetzende eigenständige Leistung.
Ebenso ist eine im Zuge einer Instandsetzungs- und/oder Erweiterungsmaßnahme erforderliche Lötung keine „Leistungseinheit“ und deshalb gesondert
bei kieferorthopädischen Geräten nach der L-Nr. 
744 0 
Metallverbindung (KFO),
bei Aufbissbehelfen nach der L-Nr. 
807 0 
Metallverbindung bei Wiederherstellung/Erweiterung
zuzüglich 75 % der tatsächlichen Lotmaterialkosten anzusetzen.
Leistungsanwendung
Zusätzliche, die „Gesamtleistung“ komplettierende Leistung.
