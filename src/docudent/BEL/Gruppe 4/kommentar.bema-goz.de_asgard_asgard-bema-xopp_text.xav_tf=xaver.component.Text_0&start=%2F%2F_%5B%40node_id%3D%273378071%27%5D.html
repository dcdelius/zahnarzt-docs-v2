▶ Kommentar zur BEL-L-Nr. 404 0
Im Rahmen der vertragszahnärzlichen Versorgung abrechenbare zahntechnische Leistung:
Leistungsbeschreibung
Die semipermanente Schiene aus Metall ist eine meist im Modellgussverfahren hergestellte breite Schiene; sie liegt meist der Lingualfläche der unteren (Schneide-)Zähne, gelegentlich auch – bei ausreichendem Abstand zu den inzisalen Antagonisten – den Palatinalflächen der oberen (Schneide-)Zähne an.
Ihre Aufgabe ist es, leicht gelockerte Zähne zu stabilisieren; zu diesem Zwecke wird sie mit den Lingual-/Palatinalflächen der natürlichen Zähne verklebt.
Der Klebeverbund setzt das Konditionieren der den Zähnen anliegenden Flächen voraus; diese zusätzliche Leistung wird unter der L-Nr. 155 0 je Zahn aufgeführt.
Fehlt ein Zahn innerhalb der zu schienenden Zahnreihe, so wird diese Leistung nach den L-Nrn. 303 0 und 362 0 aufgeführt.
Leistungsanwendung
Temporär zu tragendes, therapeutisches Hilfsmittel zur Stabilisierung leicht gelockerter Zähne.
Abrechenbar je Zahn.
Das bei Schienen erforderliche Duplikatmodell ist zusätzlich nach den L-Nrn. 002 1 und 001 0 abrechenbar.
